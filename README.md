# algo-cp-tools

算法竞赛可视化调试工具。纯网页应用，**无需构建工具**，直接用浏览器打开 `index.html` 即可使用（第三方库通过 CDN 加载，需联网）。

## 功能

多 Tab 单页应用，每个 Tab 对应一种常见算法竞赛数据结构模型。当前已实现：

### 有根树调试器

- **三种输入方式**（下拉框切换）
  - 边集合：每行 `u v` 表示从 u 到 v 的有向边
  - 父节点数组：空格/逗号分隔，`parent[i]` 为节点 `i+1` 的父节点，`0`/`-1` 表示根
  - 邻接表：每行 `k v1 v2 … vk`，k 为子节点数量，后跟 k 个子节点（第 i 行对应节点 `base+i`）
- **根节点选择**：手动输入，默认 `1`
- **属性系统**
  - 解析后自动为每个节点/边生成 `id` 字段（只读，不可删除）
  - 可添加自定义属性字段（如 `label`、`weight`、`color`）
  - 每个字段有 checkbox 控制是否在图上显示（属性级显示控制）
  - 节点表/边表可直接编辑属性值
- **三种可视化引擎**（下拉框切换）
  - **Mermaid**：生成 `graph TD` 语法，Mermaid 自行布局
  - **Graphviz**：生成 DOT 语法，viz.js dot 引擎布局
  - **TikZ**：手动计算树布局（叶子按序分配 x，内部节点取子节点中点），生成绝对定位 `tikzpicture`，由 TikZJax 在浏览器内编译为 SVG
- **自动渲染**：输入/属性/显示勾选变更后即时刷新
- **生成代码**：可展开查看并复制当前引擎生成的源码

## 使用方法

直接双击 `index.html` 打开（或拖入浏览器）。页面加载后会自带一棵示例树（7 节点），可立即渲染。

修改输入后点击「解析」重建模型；勾选/取消字段或编辑属性表后，若开启「自动渲染」会即时刷新图形。

## 技术说明

- 采用全局命名空间（`window.AlgoCPTools`）+ 传统 `<script>` 按序加载，兼容 `file://` 协议（不支持 ES6 模块）。
- CDN 依赖：
  - Mermaid `@10` — `cdn.jsdelivr.net`
  - viz.js `@2.1.2`（UMD，含 `full.render.js`）— `cdn.jsdelivr.net`
  - TikZJax — `tikzjax.com`（首次编译约 5MB，加载较慢）
- TikZ 引擎依赖浏览器内 LaTeX 编译，支持有限；若渲染失败，仍可在「生成代码」中复制 `tikzpicture` 到本地 LaTeX 环境。

### 二维几何调试器

- **多类几何实体共存输入**（每类一个可折叠输入区块，可同时填写）
  - 点：点列表（每行 `x y`）或 xy 数组（第一行 x 数组、第二行 y 数组）
  - 线段：每行 `x1 y1 x2 y2`；行首 `>` 前缀表示有向线段（渲染时终点带箭头）
  - 直线：每行 `x1 y1 x2 y2`（两点确定直线，渲染时无限延伸并裁剪到绘图区，虚线样式）
  - 多边形：空行（或 `---`）分隔多个多边形；每个多边形每行一个顶点 `x y`，至少 3 个顶点
  - 长方形：每行 `x1 y1 x2 y2`（对角线两端点，自动轴对齐）
  - 圆：每行 `cx cy r`（圆心坐标与半径，半径按绝对值处理）
- **解析与校验**：支持 `#` / `//` 注释行，非法数字报错（含行号），xy 数组长度不一致报错，多边形顶点不足、圆参数不足报错
- **计算**：轴对齐包围盒（AABB，覆盖所有实体顶点及圆边界）— minX / maxX / minY / maxY / width / height / area；线段总长、多边形周长、圆周长和、圆面积和
- **可视化**：纯 SVG 自绘，**等比例缩放**（x/y 同一 scale 并居中，圆显示为正圆、角度与比例不变形），自适应坐标范围（覆盖所有实体），含坐标轴、网格线（可开关）、刻度标签、点（序号/坐标可开关）、AABB 虚线矩形（可开关）；可选「连接点」按输入顺序连成折线
- **结果区**：实体总数/顶点数、各类数量统计表、AABB 属性表
- **状态持久化**：localStorage + sessionStorage 双写，刷新不丢数据
- **生成代码**：可展开查看生成的 SVG 源码

### 数论调试器

- **区间输入**：输入整数区间 [L, R]（L ≥ 1，R ≤ 10,000,000），用线性筛（欧拉筛）O(R) 一次性计算区间内所有整数的数论函数值；表格仅展示前 3,000 个数
- **全量统计**：素数个数与最大因数个数基于全量区间统计，与显示行数无关，计算成功后即时打印
- **8 项数论函数**（每项一列，通过 checkbox 控制显隐）：
  - **素数**：是否为素数
  - **μ(n)**：莫比乌斯函数（素数=−1，含平方因子=0，否则=(−1)^k）
  - **φ(n)**：欧拉函数（≤ n 且与 n 互素的正整数个数）
  - **d(n)**：约数个数
  - **σ(n)**：约数和
  - **ω/Ω**：ω=不同质因子个数，Ω=总质因子个数（含重复）
  - **质因数分解**：如 12 → 2²×3（上标用 Unicode）
  - **约数列表**：升序排列的全部约数
- **列显隐控制**：n 列固定显示，其余 8 列各有 checkbox，勾选/取消即时切换列显隐
- **性能**：线性筛使用 Int32Array，10^7 约 200-500ms；区间超过 5000 行时提示但仍允许计算
- **状态持久化**：localStorage + sessionStorage 双写，刷新不丢数据

### 字符串结构可视化

面向算法竞赛的字符串数据结构可视化调试工具。输入主串（AC 自动机额外输入模式串列表），选择目标结构后自动计算并自绘 SVG 渲染，帮助理解 KMP、自动机、后缀结构等核心字符串算法的内部构造。纯前端实现，离线可用，无需任何第三方库。

- **输入**：主串文本框（多行自动拼接去空白，支持 `#` / `//` 注释）；起始索引 0/1-based 切换；AC 自动机选中时显示模式串列表输入区（每行一个模式）
- **11 种结构**（按 3 组分类，分组模型按钮切换）：
  - **单串匹配与函数**
    - **KMP 前缀函数** π：π[i] = s[0..i] 最长 border 长度（O(n)）；字符串行 + π 条形图
    - **Z 算法**：z[i] = s 与 s[i..] 的最长公共前缀（z[0]=n）；字符串行 + Z-box 弧线 + Z 条形图
    - **Border 树**：节点 = 前缀长度 0..n，边 i → π[i] 的最长 border；树形布局，节点标注前缀
    - **Lyndon 分解**：Duval 算法 O(n)；字符串按因子着色分段 + 因子括号标注
  - **后缀结构**
    - **后缀数组** SA：倍增排序 O(n log n) + Kasai 求 height(LCP)；排序后缀列表 + rank/SA/height 表格 + LCP 条形
    - **后缀树**：由 SA+LCP 栈式构建 O(n)；树形布局，边标注子串，叶子标后缀位置
    - **后缀平衡树**：由 SA 构建平衡 BST（中序遍历 = 后缀字典序）；BST 布局，节点标后缀
    - **SAM 后缀自动机**：在线增量构造 O(n)；按 len 分层 DAG，转移实线标字符，suffix link 紫色虚线，clone 态橙色虚边
  - **自动机与回文**
    - **AC 自动机**：trie 插入 + BFS fail 链；trie 树 + fail 紫色虚线箭头，模式串结尾红环
    - **序列自动机**（子序列自动机）：next[i][c] 逆向填表；按状态分层 DAG，转移边标字符
    - **回文树 / Eertree**：奇偶双根 + suffix link；两棵树（奇根 len=-1 / 偶根 len=0），fail 紫色虚线
  - **变换与性质**
    - **BWT 变换**（Burrows-Wheeler）：所有循环移位按字典序排序，取末字符列（L 列）即 BWT；旋转排序表 + F/L 列对照 + BWT 结果串
    - **Runs 游程**（Run-Length Encoding）：连续相同字符的最大段；字符串按 run 着色 + RLE 编码表 + 每段起止长度
  - **位并行匹配**（需额外「模式串 P」输入框）
    - **Shift-And / Bitap**：D = ((D<<1)|1) & M[T[i]]，最高位=1 即匹配；逐位置位向量 D 表格（精确匹配，Bitap 的 k=0 形式）
    - **Shift-Or**：D = (D<<1) | R[T[i]]（匹配位为 0），最高位=0 即匹配；逐位置位向量 D 表格
    - **BNDM**：窗口内从右向左扫描 D = ((D<<1)|1) & Mrev[c]，最高位=1 即匹配；逐窗口位向量 D 表格（已与暴力匹配验证一致）
    - **BOM**（Backward Oracle Matching）：基于 reverse(P) 后缀 oracle（SAM）匹配，并用 suffix link / border 计算位移；逐窗口展示最长匹配长、匹配标记与 shift
- **可视化**：纯 SVG 自绘（离线可用），树形结构复用 `treeLayout` 布局，DAG 按深度/len 分层
- **性能**：所有算法 O(n) 或 O(n log n)，主串建议 ≤ 300 字符；按需重算（切换模型时只算当前结构）
- **状态持久化**：localStorage + sessionStorage 双写，刷新不丢数据

### 表达式计算器 / 矩阵

引入 **Algebrite**（符号代数）、**numeric.js**（数值计算）与 **math.js**（通用表达式引擎），并内置自研的安全表达式求值器（词法 + 递归下降语法分析 + 树求值），覆盖算法竞赛中验证思路、推导结论与估算规模的常用计算：

- **math.js 增强**
  - 智能求值：支持分数、大数 `BigNumber`、复数与单位；提供精确（exact）结果
  - 注入竞赛辅助函数 `gcd / lcm / modpow / comb(choose,C) / perm(P) / factorial(nthRoot)`，可直接书写 `C(10,3)`、`gcd(12,18)`、`modpow(2,10,1000)` 等并被正确解析
  - 作为「代入求值」的首选后端（精确 → 数值），失败回退到 Algebrite / 自研求值器

- **通用计算器**
  - 符号化简 `simplify`、因式分解 `factor`、求导 `d/dx`、不定积分 `∫`（Algebrite 符号计算）
  - 代入具体数值求解（如 `x=2, a=3`）：符号代入后数值化；精确结果（分数 / 大数 / 复数）优先由 math.js 给出
  - 数值积分 / 数值求导 / 方程求根（numeric.js 的 `integrate` / `derivative` / `secant`）

- **函数曲线**（独立子标签，左侧输入 / 右侧图像）
  - 输入一个或多个函数（**一行一个**，因 `comb(n,k)` 等内建函数含逗号，分隔符改用换行而非逗号，如 `sin(x)` 一行、`x^2` 一行、`a*x+b` 一行），指定 x 范围与采样点，右侧实时显示图像
  - **自定义函数**：可先在「自定义函数」块中定义（每行一个，如 `f(x) = 2*x + 1`、`P(n) = comb(n, 3)`、`g(x,k) = x^k`），再在「绘图函数」中引用；支持多参数、可调用其他自定义函数、内建函数、绘图额外参数与自变量 `x`
  - 支持**全部通用计算器函数**（含 `gcd/lcm/comb/factorial/eulerPhi/primeCount/divisorCount/omega/bigomega/mobius/partitionNumber/isPrime/nextPrime/factorize` 等）
  - **离散型 / 连续型区分**：
    - 含数论类整函数（`eulerPhi`、`primeCount`、`mobius` 等仅对正整数有意义）的曲线**自动判为离散型**，以整数点散点（圆点）绘制，不连线
    - 普通实函数自动判为**连续型**，以连线绘制
    - 可在「绘制类型」中手动覆写为「连续型（连线）」或「离散型（散点）」；图例以圆形点（连续）/ 方形点（离散）并标注「连续 · 离散」加以区分
    - 数论类函数仅对正整数自变量有效：跨实数区间绘制时非整数点被跳过、仅显示整数点；若 x 范围不含整数或越界，则在图像下方给出提示
  - 支持额外参数（如 `a=2, b=1`，绘图时作为常数；缺省按 1 处理）
  - numeric 采样 + 自研求值器，多函数叠加、自动缩放，忽略极端离群值以避免渐近线撑爆画面
  - **完整支持函数**（表达式中可直接书写，自研求值器 + math.js 注入实现）：
    - 常量：`pi` `e` `tau`(2π) `phi`(黄金比) `eps`(1e-12) `inf`(∞)
    - 三角 / 双曲：`sin cos tan asin acos atan` `sinh cosh tanh` `asinh acosh atanh` `atan2(y,x)`
    - 指数 / 对数：`exp` `log`/`ln` `log10` `log2` `logb(x,base)` `pow(a,b)` `sqrt` `cbrt`
    - 数论 / CP 工具：`gcd(a,b)` `lcm(a,b)` `modpow(b,e,m)` `comb(n,k)`/`choose`/`C` `perm(n,k)`/`P` `factorial(n)`/`fact` `isPrime(n)` `nextPrime(n)` `eulerPhi(n)`
    - 取整 / 最值：`abs floor ceil round sign` `min(…)` `max(…)`
    - 特殊函数：`erf(x)`（误差函数）`gamma(z)`（伽马函数）
    - 数论单值函数（对整数 N 可直接在表达式中调用）：`eulerPhi(n)`（欧拉函数 φ）、`primeCount(n)`（π(N) 素数个数，上限 10⁷）、`divisorCount(n)`（d(N) 因子个数）、`omega(n)`（ω 不同质因子个数）、`bigomega(n)`（Ω 总质因子个数）、`mobius(n)`（μ 莫比乌斯函数，−1/0/1）、`partitionNumber(n)`（p(N) 分拆数，上限 50000）、`factorize(n)`（质因数分解，如 `factorize(12)` → `2²×3`）
    - 语法：隐式乘（`2x` → `2*x`）、后缀阶乘（`3!`）、`^` 幂、`%` 取模
  - 例：`gcd(12,18)`、`comb(10,3)`、`modpow(2,10,1000)`、`eulerPhi(12)`、`primeCount(100)`、`mobius(30)` 均可在代入求值时求值

- **方程求解**（独立子标签，基于 nerdamer 符号代数，缺载回退 Algebrite）
  - 输入形如 `lhs = rhs` 的方程（如 `c0 = p1*c1 + p0*c0 + 1`、`x^2 - 4 = 0`、`a*x^2 + b*x + c = 0`），指定求解变量，输出该变量的解析表达式
  - 支持一次 / 二次 / 高次多项式方程的含参符号解，多解以列表形式给出（如 `x^2-4=0` → `x = 2` 与 `x = -2`）
  - 无等号的方程视为整体 = 0；其他字母均作为常数参与推导
  - **自动代入验算**：在「代入数值验证」框填入其他参数取值（如 `c1=1, p0=2, p1=3`）后求解，会自动把每个解代回方程左右两边求值并比较残差，标出验算通过 / 未通过；留空时仍可查看解析解
  - **易读美化**：每个解除原符号串外，额外给出 math.js 解析后的易读形式与可点击复制的 LaTeX 表达式

- **算法复杂度估算**
  - 输入以 `n` 为自变量的运算量表达式（自变量固定为 `n`），**支持全部通用计算器函数**：如 `n^2`、`n*log(n)`、`n*log2(n)`、`2^n`、`n!`、`comb(n,2)`、`perm(n,3)`、`factorial(n)`、`gcd(n,7)`、`eulerPhi(n)`、`min(n,1000)` 等均可参与规模估算
  - 仅评估最大数据范围内的计算量规模（不计算精确值），以科学计数法（如 `1e10`）输出，并给出竞赛时限内的可行性提示
  - 对指数 / 阶乘类采用对数尺度估算数量级，避免大数溢出；附多规模（1e3~1e7）对比表
  - 面板内置可折叠的「支持的函数与常数（全部）」清单，可直接查看

- **线性代数**（基于 numeric.js，含演示样例：2×2 可逆、对称阵、旋转阵、单位阵、非方阵、变量矩阵、函数矩阵）
  - 一元运算（作用于 A）：行列式 `det(A)`、逆 `inv(A)`、转置 `Aᵀ`、迹 `tr(A)`、秩 `rank(A)`、特征值 / 特征向量 `eig(A)`、负矩阵 `−A`、矩阵幂 `A^k`
  - 二元运算：`A + B`、`A − B`、`A × B`（矩阵乘法）、`k·A`（标量乘）
  - 线性方程组求解 `Ax = b`（numeric.js 的 `solve`）
  - **矩阵元素支持变量与函数表达式**：单元格可写数值、变量（如 `a`、`t`）或表达式（如 `sin(t)`、`a+b`、`gcd(6,4)`、`f(2)`）
    - 通过「变量取值」输入框提供 `name=value`（逗号或换行分隔），通过「自定义函数」输入框提供 `name(params)=expr`
    - 求值顺序：先按变量取值与自定义函数把每个单元格求值为数值，再进行矩阵运算
    - 列分隔规则：含表达式的行用「两个及以上空格」「竖线 `|`」「分号 `;`」或换行分列；函数参数内的逗号 / 空格不会被误拆；纯数字行仍兼容单空格或逗号分隔
    - 右端向量 `b` 同样支持表达式

> 说明：Algebrite / numeric.js / math.js 通过 CDN 加载，需联网；缺库时对应功能优雅降级（符号 / 数值功能受限，但自研求值器与矩阵秩等功能仍可用）。
