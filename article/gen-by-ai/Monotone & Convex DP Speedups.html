决策单调性与凸性加速 · Monotone & Convex DP Speedups

SMAWK / Monotone Minima / Knuth / LARSCH / CHT / Li-Chao / Aliens Trick / Kinetic …… 算法竞赛向速查笔记

总览 Overview

这一族算法在做什么
利用 DP 转移中代价函数或最优决策位置的隐藏结构（单调性、凸性、Monge 性等），把暴力的 O(n²) 乃至 O(n³) 转移降到近线性。按视角可分为：矩阵类（Monotone Minima / SMAWK / LARSCH / Knuth）、DP 结构类（D&C / Aliens）、数据结构类（CHT / Li-Chao / Kinetic / 单调队列）。

统一视角：把转移看成一张矩阵

dp[i] = minj { dp[j] + C(j, i) }

把 Ai,j = dp[j] + C(j, i) 排成一张 n×n 的矩阵，逐行取最小值。矩阵满足的性质决定能用的算法：

  • Monotone（单调）：每行最优列位置（argmin）随行号单调不减；
  • Totally Monotone（TM）：任意子矩阵都单调，等价于每个 2×2 子矩阵单调；
  • Monge（四边形不等式）：
    Ai,p + Aj,q ≤ Ai,q + Aj,p （i < j, p < q）
Monge⇒ Totally Monotone⇒ Monotone
判定顺序
Monge 最容易手工验证（直接证四边形不等式），所以实战里通常先证 Monge，再免费拿到 TM / Monotone 性。反方向的蕴含都不成立。

选型检查清单

  1. 先把转移写成矩阵形式 Ai,j=dp[j]+C(j,i)，看 argmin 是否随 i 单调——是则进入下一步。
  2. 证 C 的四边形不等式：C(a,c)+C(b,d) ≤ C(a,d)+C(b,c)。常见套路是对离散项求和 / 对区间长度求导；凸代价函数（|x−y|p, p≥1）几乎都满足。
  3. 看 DP 是分层的还是 1D1D 在线的：
    • 分层 dp[i][j] 依赖 dp[i−1][k] → D&C 优化，O(kn log n)；
    • 单层 dp[i] 依赖 dp[j]，代价矩阵 Monge → LARSCH O(n)，或退而求其次用 D&C 写法 O(n log n)。
  4. 如果是区间 DP（dp[i][j] 由 dp[i][k]+dp[k+1][j] 合并）→ Knuth 优化。
  5. 代价能写成 bj·ai+dp[j] 的线性形式 → CHT / Li-Chao，看斜率与询问的单调性决定用哪种。
  6. 约束是“恰好 K 个 / 段”且 f(x) 凸 → Aliens Trick。
  7. 查询点全局单调递增且涉及线性函数族 → 考虑 Kinetic Segment Tree。

常见误区

  • 把 Monotone 当 TM 用：Monotone Minima 只需 Monotone，SMAWK 需 TM；Monge ⇒ TM 但 TM 不 ⇒ Monge，反例存在。证 TM 最省事的路子就是证 Monge。
  • D&C 优化和 Knuth 混淆：D&C 处理“分层依赖上一层的 DP”，Knuth 处理“区间合并 DP”，形式不同；能用 Knuth 的题一定能用 D&C 风格的写法（甚至 SMAWK），反之不然。
  • Aliens Trick 忘了凸性条件：f(x) 不凸时二分可能永远碰不到 f(K)，或在整点 λ 处跳跃漏解，必须验证凹凸性。
  • LARSCH 被误当作 SMAWK 的别名：SMAWK 要求矩阵“离线可知”，LARSCH 专门处理 dp 在线生成的场景，两者不能互换。
  • 盲目追 SMAWK：D&C 常数极小，多数数据范围下 D&C 更快也更短；SMAWK 的实际收益要到百万级或访问次数受限的交互题才体现。

练习路线

入门顺序：先做 Knuth 的基础区间 DP 题（石子合并变体）→ D&C 优化 的分层 DP 题单（CF / AtCoder 上 tagged “divide and conquer optimization”）→ CHT / Li-Chao 斜率优化系列 → 进阶 Aliens Trick（USACO Tall Barn、IOI 2016 Aliens）和 SMAWK / LARSCH（IOI 2014 Holiday 是必做经典）。ko_osaga 的 Kinetic 文章和 cp-algorithms 的 CHT 页是进阶阅读的好起点。具体出处见资料来源。

Monotone Minima 单调最小值 · 决策单调性分治

性质Monotone 复杂度O((n+m) log n) 场景1D1D DP · min-plus 卷积

解决什么问题

矩阵 A 满足每行 argmin 随行号单调不减，求每行最小值位置，复杂度 O((n+m) log n)。

核心思路

经典分治：取中间行暴力扫出其 argmin，然后左上 / 右下两个子矩阵递归。因为左下和右上区域被单调性排除，每层总代价 O(n+m)。

monotone_minima.cpp · C++
// 求 argmin(row) 随 row 单调不减的矩阵每行最小值位置
void solve(int l, int r, int optl, int optr) {
    if (l > r) return;
    int mid = (l + r) / 2, best = optl;
    for (int j = optl; j <= min(optr, mid); j++)
        if (cost(mid, j) < cost(mid, best)) best = j;
    ans[mid] = best;
    solve(l, mid - 1, optl, best);
    solve(mid + 1, r, best, optr);
}

适用判定

写出矩阵 Ai,j = dp[j] + C(j, i)，如果 i 增大时最优 j 单调不减，即可用。实际操作中大多是先证 C 满足四边形不等式（Monge），从而推出矩阵单调。

延伸应用：min-plus 卷积

一个不太显然的应用：Ci = minj{Aj + Bi−j}，当 B 是下凸序列时，把 Aj + Bi−j 排成矩阵后是 Monge 的，于是可以 O(n log n) 求卷积。

相关：SMAWK · D&C 优化 · Min-plus 卷积

SMAWK Totally Monotone 矩阵行最小值

性质Totally Monotone 复杂度O(n+m) 场景Monge 行最小值 · IOI 2014 Holiday · Milutin's Plums

解决什么问题

Totally Monotone 矩阵的行最小值，O(n+m)，比 Monotone Minima 少一个 log。

算法结构

  • Reduce：用栈删列，把列数压到不超过行数；
  • Interpolate：只递归奇数行，再由相邻奇数行夹出偶数行的候选范围。

与 D&C 的关系

SMAWK 能用的地方 D&C 一定能用（TM ⇒ Monotone），反之不成立。但实测 D&C 常数极小，几千到几十万规模时往往 D&C 更快；SMAWK 的优势要到百万级才显现，或者题目限制了矩阵访问次数（如只允许 4(n+m) 次询问）时才必须用。

实战建议
除非卡常，一般用 Monotone Minima / D&C 就够了；SMAWK 当作“知道存在、需要时能抄”的工具即可。
相关：Monotone Minima · LARSCH · Knuth 优化

D&C Optimization 分治优化

性质Monotone（opt 单调） 复杂度O(kn log n) 场景分层 DP

解决什么问题

分层 DP：

dp[i][j] = mink<j { dp[i−1][k] + C[k][j] }

其中 C 满足四边形不等式（等价于每层内部 opt 单调）。复杂度从 O(kn²) 降到 O(kn log n)。

与 Monotone Minima 的区别

D&C 优化处理的是“转移依赖上一层 dp”的分层结构，而 Monotone Minima 处理的是单层内已知代价矩阵的行最小值。本质上，D&C 优化每层就是在跑一次 Monotone Minima。

相关：Monotone Minima · Knuth 优化 · LARSCH

Knuth Optimization Knuth-Yao Speedup

性质四边形不等式 + 区间单调 复杂度O(n²)（原 O(n³)） 场景区间 DP · 石子合并 · 最优 BST

解决什么问题

区间 DP：

dp[i][j] = mini≤k<j { dp[i][k] + dp[k+1][j] } + C[i][j]

其中 C 满足四边形不等式 + 区间单调，复杂度 O(n²)（朴素 O(n³)）。

核心：决策点单调

K(i, j−1) ≤ K(i, j) ≤ K(i+1, j)

按区间长度从小到大填表时，每个 dp[i][j] 只需在 [K(i,j−1), K(i+1,j)] 这个小区间内枚举 k，总枚举量 O(n²)。

经典题目

石子合并、最优二叉搜索树（这正是 Knuth 1971 年原始论文处理的问题）、Breaking String。

理论注记

Bein–Golin–Larmore–Zhang (2009) 证明了 Knuth-Yao 能用的地方 SMAWK 也能用，两者本质同源。

相关：D&C 优化 · SMAWK

LARSCH 在线 Totally Monotone 行最小值

性质Totally Monotone + 在线 复杂度O(n) 场景1D1D 在线 DP

解决什么问题

dp[i] = minj { dp[j] + C(j+1, i) }

C 为 Monge，但 DP 是在线的——dp[i] 本身参与后面的转移，不能预先整张矩阵。LARSCH 做到 O(n)。

本质：在线版 SMAWK

它保证算第 i 行的 argmin 时，只用到已经算好的 dp[1..i−1]，正好匹配自底向上的 DP 顺序。如果题目是这个形式（转移代价 Monge、dp 自己也在矩阵里），LARSCH 是唯一能做到 O(n) 的算法；SMAWK 和 Monotone Minima 都因为“需要整行先知道”而不可用。

实现

LARSCH 实现上比较繁琐，竞赛中 noshi91 等人的库有现成模板（见资料来源）。很多场合用 D&C 优化（O(n log n)）也能过。

相关：SMAWK · D&C 优化

Convex Hull Trick 斜率优化 · CHT

性质斜率单调 复杂度O(n) / O(n log n) 场景线性转移 DP

解决什么问题

dp[i] = minj { dp[j] + bj·ai }

把每个 j 看成直线 y = bjx + dp[j]，每次在 x = ai 处取最小值。

三种情形

  • 斜率 bj 单调、询问 ai 也单调：单调栈 / 双端队列维护下凸壳，均摊 O(1)；
  • 斜率单调但询问任意：凸壳上二分，O(log n)；
  • 完全动态（任意插入）：Li-Chao 树 或平衡树维护动态凸壳。

判定要点

把转移重写成 bj·ai + dp[j] 的“斜率 × 自变量 + 截距”形式，看 bj 和 ai 的单调性。

相关：Li-Chao 树 · Kinetic 段树 · 单调队列

Li-Chao Segment Tree 李超线段树

性质无需单调 复杂度O(log n) 插入 / 查询 场景动态插线段

解决什么问题

CHT 的动态版：线段树每个节点存“在该区间中点最优的线”，插入时与节点当前线比较，留优去劣递归一侧。不需要任何单调性，插入 / 查询均 O(log n)，实现比动态 CHT 简单很多。

何时首选
当插入顺序或询问顺序无法保证单调时，Li-Chao 是首选。
相关：斜率优化 CHT · Kinetic 段树

Aliens Trick WQS 二分 · Lagrangian 松弛

性质f(x) 凸（或凹） 复杂度O(n log V) 场景恰好 K 段的划分 DP

解决什么问题

形如“恰好选 K 段 / K 个物品”的 DP，朴素需要带一维状态记录已选个数。Aliens Trick 去掉这一维：给每次“开新段”附加惩罚 λ，变成无约束 DP dpλ（O(n)），再二分 λ 使选的段数恰好等于 K。

适用条件：f(x) 必须凸（或凹）

f(x) 是“选 x 段的最优值”，要求 f(x) 的差分单调，这样 f(x) − λ·x 才能通过 λ 的调整触到 f(K) 这个点。二分时选“最大 / 最小的 λ 使段数 ≥ K”（或 ≤ K，方向取决于凹凸），答案为 v(λ) + λ·K。

经典题目

IOI 2016 Aliens（名字即由此而来）、USACO 2017 Tall Barn、CF 868F 等“恰好 K 段最大和 / 最小代价”题。

常见坑

  • 不凸时（f 有拐点）会二分到错误答案；
  • 整点 λ 时可能多个 λ 对应同一 K，需要选对边界方向；
  • 答案要回加 λ·K，而不是直接用 dpλ。
相关：D&C 优化 · 斜率优化 CHT

Kinetic Segment Tree Kinetic Tournament

性质函数交点 O(1) 次 复杂度均摊 O(n log² n)（heaten） 场景时间递增的区间线性函数最小值

解决什么问题

维护 n 条直线 Ait + Bi，支持：

  • 区间更新、区间查询 mini∈[l,r] Ait + Bi：每次 O(log n)；
  • 全局“加热”heaten（时间 t 单调前进）：总代价均摊 O(n log² n)（线性函数情形）。

理解与实现

可以把它理解成“支持区间查询的 Li-Chao + 时间递增”。核心技巧：每个线段树节点记子树内“最小值何时会换人”的阈值 melt，heaten 时沿根向下找过期节点重建——这正是 Segment Tree Beats 的势能分析思路。它出自 ko_osaga 的文章，竞赛中已出现在 FBHC Round 2（Kinetic Tournament 名字即来自 CF 上的讨论）。

适用场景

查询的 x（时间）整体单调递增、函数是线性或至多相交常数次的曲线。函数相交次数是 s 时复杂度变为 O(λs+2(n) log² n)，s 小时近似线性。

相关：Li-Chao 树 · 斜率优化 CHT

单调队列 / 单调栈 Sliding Window Optimization

性质滑动窗口 复杂度均摊 O(1) 场景窗口类 DP

解决什么问题

dp[i] = mini−k ≤ j < i { dp[j] } + Ci

这类滑动窗口最小值，用单调队列做到均摊 O(1) 转移。它其实是 Monotone Minima 在“窗口固定宽度”退化情形下的特例，也是最基础、最常被忽略的一类优化。

相关：斜率优化 CHT · Monotone Minima

Min-plus Convolution (min, +) 卷积的单调 / 凸版本

性质一侧凸 复杂度O(n)（凸+任意）/ 归并（凸+凸） 场景分层背包 · 期望 DP

解决什么问题

Ci = minj { Aj + Bi−j }

一般的 (min,+) 卷积被认为是无法显著亚二次的（有 SETH 类下界）。但当一侧序列是凸的：

  • 一侧凸：借助 Monge 矩阵行最小值做到 O(n)；
  • 两侧都凸：就是 Minkowski 和，直接归并。

这个技巧在分层背包、期望 DP 中频繁出现。

相关：Monotone Minima · SMAWK
