## Stirling 数除以 $p$ 的余数的计算（Stirling 数を $p$ で割った余りの計算）

### 概要

用下降幂 $(x)_n$、带符号第 1 类 Stirling 数 $s(n,k)$、第 2 类 Stirling 数 $S(n,k)$ 如下定义：

$$(x)_n = \prod_{0\leq i < n} (x-i) = \sum_{k=0}^{n} s(n,k)x^k$$

$$x^n = \sum_{k=0}^n S(n,k)(x)_k$$

这些的组合意义等，请参考例如：

https://ja.wikipedia.org/wiki/スターリング数

另外，对常数 $N$，枚举 $s(N, k)$ 或 $S(N, k)$ 都可以在 $O(N\log N)$ 时间内完成。

- https://judge.yosupo.jp/problem/stirling_number_of_the_first_kind
- https://judge.yosupo.jp/problem/stirling_number_of_the_second_kind

关于解法，在我的文章 [多项式・形式幂级数] 能快速计算的东西们 中也提到过。

本文解说在如下复杂度下求 $s(n,k), S(n,k)\pmod{p}$ 的方法：

- $O(\log_p n + p\log p)$ 时间计算
- 在 $O(p^2)$ 时间预处理的前提下，$O(\log n)$ 时间计算

竞技编程中也似乎出过几次题。

以下固定素数 $p$，整数与多项式的等式都视为 $\mathbb{F}_p$ 上（$\mod{p}$ 下）的等式。

### 下降幂的性质

对非负整数 $i, j$，如下成立：

$$(x)_p = x^p-x, \qquad (x)_{ip+j} = (x^p-x)^i(x)_j$$

$(x)_p = x^p-x$ 可由 Fermat 小定理与因式定理（在域 $\mathbb{F}_p$ 中）证明。$(x)_{ip+j}$ 把每 $p$ 项分组后使用 $(x)_p = x^p-x$ 即可。

### 第 1 类 Stirling 数的计算

第 1 类 Stirling 数 $s(n,k)$ 就是下降幂的系数 $[x^k] (x)_n$。令 $n = ip+j$ ($0\leq j\leq p-1$)，由上面讲过的下降幂性质，

$$s(n,k) = [x^k] (x^p-x)^i(x)_j = [x^{k-i}] (x^{p-1}-1)^{i}(x)_j=[x^{k-i}]\sum_{a=0}^{i}\sum_{b=0}^{j}\binom{i}{a}x^{(p-1)a}(-1)^{i-a}\cdot s(j,b)x^b$$

于是

$$X = \{(a,b)\mid k-i=(p-1)a+b, 0\leq a\leq i, 0\leq b\leq j\}$$

则 $s(n,k) = \sum_{(a,b)\in X} (-1)^{i-a}\binom{i}{a}s(j,b)$ 成立。

固定 $n,k$ 时，$X$ 至多是 $2$ 元集合。虽可能有对应于 $b=0, p-1$ 的 $2$ 元模式，但这种情形由 $s(0,p-1)=0$ 或 $s(j,0)=0$ ($j>0$) 可知，使 $s(j,b)\neq 0$ 的 $(a,b)$ 是唯一的。因此该情形下，使 $s(n,k) = (-1)^{i-a}\binom{i}{a}s(j,b)$ 成立的 $(a,b)$ 恰好存在一个。

### 第 2 类 Stirling 数的计算

由 $x^n = \sum_{k=0}^n S(n,k)(x)_k$ 求 $S(n,k)$。由下降幂性质可变形为

$$x^n = \sum_{i=0}^{\infty}\sum_{j=0}^{p-1} S(n,ip+j) (x^p-x)^i(x)_j$$

因此，$S(n,ip+j)$ 可用如下步骤计算：

- 求 $x^n$ 在 $x^p-x$ 进制展开下 $(x^p-x)^i$ 的系数 $g_i(x)$，即求满足 $x^n = \sum_{i=0}^{\infty} g_i(x)(x^p-x)^i$ 的次数低于 $p-1$ 的多项式 $g_i$。
- 由 $g_i(x) = \sum_{j=0}^{p-1} S(n,ip+j) (x)_j$ 求 $S(n,ip+j)$。

取整数 $a,b$ 使 $n = (p-1)a+(i+b)$ 且 $1\leq b\leq p-1$。

由 $x^{n-i-b}=\bigl((x^{p-1}-1)+1\bigr)^a = \sum_{k=0}^{a}\binom{a}{k}(x^{p-1}-1)^k$ 得

$$x^n = \sum_{k=0}^a\binom{a}{k}(x^{p-1}-1)^kx^{i+b}$$

成立。

- 对应 $k\geq i+1$ 的项，可被 $(x^{p-1}-1)^{i+1}x^{i+1}=(x^p-x)^{i+1}$ 整除，因此对 $(x^p-x)$ 进制展开中 $(x^p-x)^i$ 的系数没有贡献。
- 对应 $k\leq i – 2$ 的项，次数最高为 $(p-1)k+i+b\leq pi – 2(p-1)+b < pi$，因此对 $(x^p-x)$ 进制展开中 $(x^p-x)^i$ 的系数没有贡献。

于是，要求 $g_i(x)$，只需看 $k=i, i-1$ 的部分

$$\binom{a}{i}(x^p-x)^ix^b + \binom{a}{i-1}(x^p-x)^{i-1}x^{b+1}$$

做 $(x^p-x)$ 进制展开即可。因此可知：

- 若 $1\leq b < p – 1$，则 $g_i(x) = \binom{a}{i}x^b$
- 若 $b = p-1$，则 $g_i(x) = \binom{a}{i}x^{p-1}+\binom{a}{i-1}$

由此关于第 2 类 Stirling 数可得：

- 若 $1\leq b < p-1$，则 $S(n,ip+j) = \binom{a}{i}S(b,j)$
- 若 $b=p-1$，则 $S(n,ip+j) = \binom{a}{i}S(p-1,j) + \binom{a}{i-1}S(0,j)$

后者乍看是 $2$ 项之和，但依 $j=0$ 与否，恰有 $S(p-1,j)$ 与 $S(0,j)$ 中仅一方非零。无论如何，找到了使 $S(n,k) = \binom{a}{i}S(b,j)$ 恰好成立的一对 $(a,b)$。

### 总结

证明了以下事实：

- 给定 $n,k$ 时，使 $s(n,k) = (-1)^{i-a}\binom{i}{a}s(j,b)$ 成立的 $i,j,a,b$ ($0\leq b \leq j\leq p – 1$) 可在 $O(1)$ 时间内算出。
- 给定 $n,k$ 时，使 $S(n,k) = \binom{a}{i}S(b,j)$ 成立的 $i,j,a,b$ ($0\leq j\leq b\leq p-1$) 可在 $O(1)$ 时间内算出。

由此，$s(n,k)$ 与 $S(n,k)$ 可通过

- $n\leq p-1$ 情形的计算
- 二项式系数的计算

来求得。所有 $n\leq p-1$ 情形的 $s(n,k), S(n,k)$ 整体可在 $O(p^2)$ 时间预处理。不预处理时也能在 $O(p\log p)$ 时间计算。

### 二项式系数除以 $p$ 的余数的计算

虽然有名，顺便也讲一下。计算 $\binom{n}{k} = [x^k](1+x)^n$。

利用在域 $\mathbb{F}_p$ 中（或 $\mod p$ 下）$(1+x)^p = 1+x^p$ 成立。

把 $n,k$ 写成 $p$ 除的商与余数：$n = n_0 + pn_1, k = k_0 + pk_1$ ($0\leq k_0,n_0\leq p-1$)，则

$$\binom{n}{k}=[x^k](1+x)^n=[x^{k_0+pk_1}](1+x)^{n_0}(1+x^p)^{n_1} = \binom{n_0}{k_0}\cdot [x^{pk_1}](1+x^p)^{n_1} = \binom{n_0}{k_0}\cdot \binom{n_1}{k_1}$$

得到。这个性质作为 Lucas 定理而知名。

由此，在 $n < p$ 情形的二项式系数预处理基础上，$\binom{n}{k}$ 可在 $O(\log_pn)$ 时间计算。
