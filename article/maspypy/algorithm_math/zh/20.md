### 前提知识

本文为简单，设字母表为 $\Sigma = \{0,1,\ldots,\sigma-1\}$。若是英文字母，用 ASCII 码把字母对应到小于 $128$ 的整数，或平移对应到小于 $26$ 的整数，就能把字母视为整数。

### Rolling Hash 是什么

Rolling Hash 是把字符串 $S = S_0,S_1,S_2,\ldots$ 如下 Hash 化的手法：

**【Rolling Hash】** 以某方法取模 $m$、基数 $r$。字符串 $S = S_0,S_1,S_2,\ldots$ 的 Hash 值定义为 $\mathrm{hash}(S) = \sum S_i r^i\pmod{m}$。

计算的容易性，特别是适当预处理下任意子串的 Hash 值都能每件 $\Theta(1)$ 时间算出，这一点出色。对此 Hash 值，期待如下。

**【期待】** $\mathrm{hash}(S)$ 在 $\pmod{m}$ 下大概随机吧。因此对字符串 $S, T$ $(S\neq T)$，$\mathrm{hash}(S) = \mathrm{hash}(T)$ 的概率大概 $1/m$ 吧。

例如以下条件成立时这是正确的：

- $r$ 与 $m$ 互素。
- $N$ 为充分大的自然数，$S$, $T$ 是从长度 $N$ 以下字符串全体中完全随机选的。

顺便，连此主张的证明似乎都没见过，故本文末尾以附录记之。

### 对抗性输入与随机算法

此主张虽正确，但由此唱此 Hash 函数的万能性却不行。上述条件中，前提 $S, T$ 从任意字母列完全随机选。但例如“从世间书籍随机选的长度 $N$ 字符串”这种情形，输入字符串应有某种偏倚（例如元音 a, i, u, e, o 的出现比例会比 $1/\sigma$ 高）。对有偏倚的字符串群，上述概率分析未必成立。

特别这种概率分析中，作为 worst case 的、对（对抗性的/恶意的）输入的概率分析常被讨论。本文也以此为主题。

**【问题】** 攻击者可在确认 $m$, $r$ 的选择算法后，选字符串 $S$, $T$ $(S\neq T)$。把 $\mathrm{hash}(S) = \mathrm{hash}(T)$ 的概率压低（对可实现的概率做考察）。

无论多巧妙地定值，一旦使用的 $m, r$ 值被固定，那一刻就完全败北。那怎么办？解决这种问题的一般方法有随机算法。特别地讨论如下解决策。

**【随机算法】** 预先固定 $m$。随机取 $0\leqq r < m$。用此 $m, r$ 计算 Hash 值。

用随机化，即使对抗性攻击者也难故意造成 hash 冲突。

### 基本评价

**【定理１】** 把 $m$ 作素数用上述手法，则对任一长度 $N$ 的字符串 $S, T$ $(S\neq T)$，$\mathrm{hash}(S) = \mathrm{hash}(T)$ 的概率在 $\frac{N}{m}$ 以下。

证明如下。

$\mathrm{hash(S)}$ 等于某多项式 $f_S$ 的值 $f_S(r)$。Hash 冲突发生的条件可写为 $f_S(r)-f_T(r) = 0$。$f = f_S-f_T$ 是 $0$ 次以上的 $N$ 次以下多项式。在体中，$0$ 次以上的 $N$ 次以下多项式至多只有 $N$ 个根，故使 Hash 冲突的 $r$ 至多 $N$ 种。因此若随机取 $r$，其概率在 $\frac{N}{m}$ 以下。

注意1：在体中，$N$ 次多项式根在 $N$ 个以下，由因式定理可知。在实数或复数证过的人，请确认在任意体完全相同。$N$ 个解存在则 $f(x) = 0\iff c(x-a_1)\cdots(x-a_N) = 0$ 这样变形，再由是体知无其他解。

注意2：任意环不成立，例如环 $\Z/8\Z$ 中 $2$ 次方程 $x^2 -1 = 0$ 有 $4$ 个解 $x=1,3,5,7$。

### 对冲突概率的详细考察（本文主题）

固定素数 $m$ 随机取 $r$ 时，考察对抗性输入的 Hash 冲突概率。此问题可改写如下。

**【问题】** 考虑 $N$ 次多项式 $f = \sum_{i=0}^N a_i x^i$（其中 $0\leqq |a_i| < \sigma$）。巧妙取 $f\neq 0$ 使根尽量多时，评价根的个数 $\mathrm{root}(N)$。

关于此问题，报告得到如下结果。

**【定理２】** 成立：
$$\biggl\lceil\frac{N+1}{\log_{\sigma}m}\biggr\rceil – 1 \leqq \mathrm{root}(N)\leqq N.$$

右边是【定理１】所得的自明评价。左边是本文的主结果，给出“固定模、随机取 $r$”情形的非自明性能界限。即，采用“固定 mod 与随机取 $r$”这一手法时，不得不接受冲突概率约 $\frac{N+1}{m\log_{\sigma} m}$ 的攻击。

来证明。如下定义集合 $A$, $A_+$：
$$A = \{f(x) = \sum_{i=0}^N a_ix^i\mid 0\leqq |a_i| < \sigma\},\qquad A_+ = \{f(x) = \sum_{i=0}^N a_ix^i\mid 0\leqq a_i < \sigma\}.$$

只需证存在 $k = \bigl\lceil\frac{N+1}{\log_{\sigma}m}\bigr\rceil – 1$ 个根的 $f \in A\setminus \{0\}$。特别地，证存在使对 $r=0,1,\ldots, k-1$ 有 $f(r) = 0$ 的 $f\in A \setminus \{0\}$。

用 $\mathrm{eval}\colon A_+\longrightarrow (\Z/m\Z)^k$，$\mathrm{eval}(f) = \bigl(f(0), f(1), \ldots, f(k-1)\bigr)$ 定义。成立 $|A_+| = \sigma^{N+1}$, $|(\Z/m\Z)^k| = m^k$，且由 $k$ 的取法成立 $|A_+| > |(\Z/m\Z)^k|$。因此某 $f_1, f_2\in A$（其中 $f_1\neq f_2$）满足 $\mathrm{eval}(f_1) = \mathrm{eval}(f_2)$。它们的差 $f = f_1 – f_2 \in A$ 满足条件。由此存在得证。

注意：非构造性的存在证明。虽证了存在，基于此证明方法的攻击或许困难。

**【定理３】** 固定互素正整数 $m, r$。取正整数 $N$，令 $A_+ = \{f(x) = \sum_{i=0}^N a_ix^i\mid 0\leqq a_i < \sigma\}$。当 $N$ 充分大时，对 $f\in A_+$，$f(r)\in \Z/m\Z$ 均等分布。即对任意 $k$ 成立 $\lim_{N\to\infty}\frac{|\{f\in A_+\mid f(r) = k\}|}{|A_+} = \frac{1}{m}$。

本文当作附赠，只留方针说明。有稍难的行间，敬请见谅。

只需证使 $r^i \equiv 1\pmod{m}$ 的 $i$ 全体集合 $I$ 中 $\sum_{i\in I} a_i$ 均等分布。用多项式调查此分布。

对充分大的 $N$ 与 $f = 1 + x + \dots + x^{\sigma-1}$，只需评价 $\sum_{i\equiv k\pmod{m}}[x^i]f^N$。令 $g = x^{m-k}f^N$，只需评价 $\sum_{i\equiv 0\pmod{m}}[x^i]g$。

此值可用 $1$ 的 $m$ 次根全体 $\mu_m = \{e^{2\pi i\cdot (j/m)}\in\C \mid 0\leqq j < m\}$ 写为 $\frac{1}{m}\sum_{\zeta\in \mu_m}g(\zeta)=\frac{1}{m}\sum_{\zeta}\zeta^{m-k}f(\zeta)^N$。对 $N$，是公比为 $f(\zeta)$ 的等比数列的线性组合。复绝对值 $|f(\zeta)|$ 仅当 $\zeta = 1$ 时取最大值 $\sigma$。$N\to\infty$ 极限中其他 $\zeta$ 的贡献被忽略，得到 $N\to\infty$ 极限下的均匀分布。

考虑 $0,1,\ldots, \sigma – 1$ 均匀变动的随机变量 $X$ 加 $N$ 个的分布。对随机变量 $X$，其矩母函数 $M_X(t) = E(e^{tX})$ 或特征函数 $\phi_X(t) = M_X(it)$，对独立随机变量 $X_1, \ldots, X_N$ 有 $M_{X_1+\cdots+X_n}(t) = \prod_i M_{X_i}(t)$ 的性质，是分析概率分布卷积的定石手法（与 Fourier 变换几乎相同，函数卷积转换为点积的）。
