## 关于素数的上界估计（初等证明）（素数に関する上からの評価（初等的な証明））

### 概要

本文中总是用 $p$ 表示素数，$i, k, n$ 表示整数，$x$ 表示实数。特别地，直接写 $\sum_{p\leq x}$ 或 $\prod_{p\leq x}$ 等，表示对素数求和或求积。

记 $\pi(x) := \sum_{p\leq x}1$。也就是说，$\pi(x)$ 是不超过 $x$ 的素数个数。另外文中 big-O 记号是关于 $x\to \infty$, $N\to\infty$, $n\to\infty$ 等的。

本文证明以下事实：

**【素数个数的弱估计】** $\pi(x) = O\left(\frac{x}{\log x}\right)$

**【素数倒数和的弱估计】** $\sum_{p\leq x}\frac{1}{p} = O(\log\log x)$

关于该问题，例如存在如下更强的结论，但本文不证明：

**【素数个数的强估计（素数定理）】** $\lim_{x\to \infty}\pi(x)\div \frac{x}{\log x} = 1$

**【素数倒数和的强估计】** $\sum_{p\leq x}\frac{1}{p} = \log\log x + O(1)$

另外，进一步精细估计误差的命题也是已知的。

竞技编程的资料中也常介绍这些“强估计”，但因为结果强，证明常被省略，容易让人产生“素数个数的阶估计很难”的误解。然而（对于竞技编程语境中多数目的应该够用的）“弱估计”，用高中数学水平就能简单证明。

那开始吧。

### 二项式系数与素数

**【補題】** 对正整数 $N$ 如下成立：$$\prod_{N < p\leq 2N} p \leq \binom{2N}{N} \leq 2^{2N}$$

**【証明】**

$\binom{2N}{N} = \frac{(2N)!}{N!N!}$。当 $N < p\leq 2N$ 时，$p$ 整除分子 $(2N)!$，但不整除分母 $N!$。故知 $\binom{2N}{N}$ 是 $p$ 的倍数。又因满足 $N < p\leq 2N$ 的 $p$ 两两互素，于是 $\binom{2N}{N}$ 是 $\prod_{N < p \leq 2N} p$ 的倍数，左边不等式得证。

右边不等式由 $2^{n} = (1+1)^n = \sum_{k=0}^n \binom{n}{k}$ 知任意 $0\leq k\leq n$ 有 $\binom{n}{k}\leq 2^n$ 而得。

### 不等式估计 (1)

由上述不等式得 $\sum_{N < p \leq 2N} \log_2 p\leq 2N$。接下来基本就是照做。姑且认真做一遍。

与代数变形不同，解析的不等式估计或近似计算，即使是同一内容，式变形也有相当大的自由度，请当作只是一例来看。

取 $N = 2^k$，有 $\sum_{2^k < p \leq 2^{k+1}} \log_2 p\leq 2^{k+1}$。范围内 $p$ 满足 $k < \log_2 p$，故 $\sum_{2^k < p\leq 2^{k+1}}1\leq \frac{2^{k+1}}{k}$。对 $k = 1, 2, \ldots, n$ 求和，得如下估计：

$$\pi(2^{n+1}) \leq 1 + \sum_{k=1}^n\frac{2^{k+1}}{k}$$

也看一下素数倒数和。$2^k < p\leq 2^{k+1}$ 时 $\frac{1}{p} \leq \frac{1}{2^{k}}$，故 $\sum_{2^k < p\leq 2^{k+1}}\frac{1}{p}\leq \frac{1}{2^k}\sum_{2^k < p\leq 2^{k+1}}1\leq \frac{2}{k}$。对 $k = 1, 2, \ldots, n$ 求和，得如下估计：

$$\sum_{p\leq 2^{n+1}} \frac{1}{p} \leq \frac12 + \sum_{k=1}^n\frac{2}{k}$$

### 不等式估计 (2)

### 调和级数

有著名结果 $\sum_{k=1}^N\frac{1}{k} = \log n + O(1)$。用积分的方法很简洁。但关于这个也偶尔有误会，以为不知道积分就无法估计阶，所以这里用更初等的方法说明 $\sum_{k=1}^N\frac{1}{k} = O(\log N)$。取满足 $2^n\leq N < 2^{n+1}$ 的 $n$。

$2^i\leq k < 2^{i+1}$ 时 $\frac{1}{k}\leq 2^{-i}$。于是 $\sum_{k=2^i}^{2^{i+1}-1}\frac{1}{k}\leq \sum_{k=2^i}^{2^{i+1}-1}2^{-i} = 1$。对 $i=0, \ldots, n$ 累加，得 $\sum_{k=1}^{2^{n+1}-1}\frac{1}{k} \leq n+1$。

由此得 $\sum_{k=1}^N\frac{1}{k}\leq \sum_{k=1}^{2^{n+1}-1}\frac{1}{k} \leq n + 1\leq \log_2N + 1$。特别地 $\sum_{k=1}^N\frac{1}{k} = O(\log N)$。

### 素数倒数和

结合调和级数的不等式估计，得

$$\sum_{p\leq 2^{n+1}} \frac{1}{p} \leq \frac12 + \sum_{k=1}^n\frac{2}{k}\leq \frac12 + 2(\log_2n+1)$$

取 $x\in \R$，取满足 $2^n\leq x < 2^{n+1}$ 的 $n$，则

$$\sum_{p\leq x}\frac{1}{p} \leq \sum_{p\leq 2^{n+1}} \frac{1}{p}\leq \frac12 + 2(\log_2n + 1)\leq \frac12 + 2(\log_2\log_2x+1)$$

得证 $\sum_{p\leq x}\frac{1}{p} = O(\log_2\log_2 x)$。又由

$$\log_2\log_2x = \log_2\frac{\log x}{\log 2} = \log_2\log x – \log_2\log 2 = \frac{\log\log x}{\log 2} – \log_2\log 2$$

可知，本次证明的估计也可写成 $\sum_{p\leq x}\frac{1}{p} = \frac{2}{\log 2}\log\log x + O(1) \leq 2.886\cdot\log \log x + O(1)$。比最优估计弱了约 $3$ 倍。

### 素数个数

估计 $\pi(2^{n+1}) \leq 1 + \sum_{k=1}^n\frac{2^{k+1}}{k}$ 的右边。简单说，就是估计 $k = n$ 时的 $\frac{2^{n+1}}{n}$ 在总和里占了足够大的比例。令 $i = n – k$，例如如下处理：

$$\begin{align*}\sum_{k=1}^n\frac{2^{k+1}}{k} &= \sum_{i=0}^{n-1}\frac{2^{n-i+1}}{n-i} = \frac{2^{n+1}}{n}\sum_{i=0}^{n-1}\frac{n}{n-i}2^{-i}\\&=\frac{2^{n+1}}{n}\left(\sum_{i=0}^{n-1}2^{-i} + \sum_{i=1}^{n-1}\frac{i}{n-i}2^{-i}\right)\\&\leq \frac{2^{n+1}}{n}\left(\sum_{i=0}^{\infty}2^{-i}+\sum_{i=1}^{\infty}i 2^{-i}\right) = \frac{4\cdot 2^{n+1}}{n}\end{align*}$$

于是得 $\pi(2^{n+1})\leq 1 + \frac{4\cdot 2^{n+1}}{n}$。

取 $x\in \R$，取满足 $2^n\leq x < 2^{n+1}$ 的 $n$，则

$$\pi(x)\leq \pi(2^{n+1})\leq 1 + \frac{4\cdot 2^{n+1}}{n}\leq 1 + \frac{8x}{\log_2x-1} = \frac{8x}{\log_2 x} + O(1)$$

从而 $\pi(x) \leq \frac{8x}{\log_2x} + O(1)$，特别地 $\pi(x) = O(\frac{x}{\log x})$ 得证。

由 $\frac{8}{\log_2x} = \frac{8\log 2}{\log x} \leq 5.55\cdot \frac{x}{\log x}$，比最优估计弱了约 $6$ 倍。

### 其他评论

得到的估计虽弱，但属于“【補題】一发”那样的简单证明。在式变形的细节处应该还能改善估计。

本文处理的是“素数很少”方向的估计，但“素数很多”即 $\pi(x)\geq c\cdot \frac{x}{\log x}$ 这样的估计也能用初等方法做到。例如关注 $\binom{2N}{N}$，由 $p\leq 2N$ 的指数足够小就能估计，从而可证 $\pi(x) = \Theta\left(\frac{x}{\log x}\right)$ 以及 $\sum_{p\leq x} \frac1p = \Theta(\log\log x)$。有兴趣的话可以想一想。另外关于下界估计，也有利用由 Euler 积可知的 $\sum_{1\leq n\leq x}\frac{1}{n}\leq \prod_{p\leq x}\left(1-\frac{1}{p}\right)^{-1}$ 等方法。
