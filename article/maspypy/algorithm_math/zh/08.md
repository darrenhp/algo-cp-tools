## 关于幺半群作用的离散对数问题（モノイド作用に関する離散対数問題）

### 概要

本篇处理如下离散对数问题的变种。

设 $X$ 为幺半群，$S$ 为集合，且 $X$ 在 $S$ 上左作用。给定 $x\in X$ 以及 $s, t \in S$ 以及正整数 $N$。判定是否存在满足下式的非负整数 $n$ 并求其中最小者：$x^ns = t$ 且 $0\leq n < N$。

当幺半群的运算与作用、以及 $S$ 中元素的哈希都能在 $O(1)$ 时间计算时，目标是期望时间 $O(\sqrt{N})$ 解此问题。若想对任意非负整数求最小的 $n$，取 $N = |S|$ 即可。

左作用是指映射 $X\times S\longrightarrow S; (x,s) \longmapsto xs$，满足单位元平凡地作用、且 $(x_1x_2)s = x_1(x_2s)$。本篇范围内只出现对固定 $x$ 的 $x^n$ 形元素，所以不需要区分运算的左右（因此写了“左作用”，但“右作用”情形也一样）。

上面的问题，在特殊情形下包含如下所谓的“离散对数问题”（wikipedia）：

设 $X$ 为群，$x, y \in X$。判定是否存在满足 $x^n = y$ 的非负整数 $n$，若存在则求出。

具体取 $S = X$，把群运算本身视为作用、$s$ 取单位元即可。

离散对数的解说文章中似乎很多处理这个特殊情形，但我经常看到无法直接套用其形式化的竞技编程问题，所以构思了本篇的形式化与手法。例如，如下问题是本篇的直接适用范围：

给定 $m, a, b, s, t$。考虑 $f(x) = (ax+b)\bmod m$ 这个函数。$f^n(s) = t$（左边是 $n$ 次复合）是否存在满足的 $n$？若存在则求其中最小的。

这对应取 $X$ 为 $\mathbb{Z}/m\mathbb{Z}$ 上的仿射函数全体（运算为复合）、$S = \mathbb{Z}/m\mathbb{Z}$。

这个问题在假设 $X=S$ 的形式化下我觉得不好直接处理。另外，即使不假设 $\gcd(a,m) = 1$，也希望不利用同余式性质等而能直接适用的解法。

本篇的算法，是竞技编程中熟知的 baby step giant step 算法的变种，但在幺半群（不一定是群）的形式化下，需要注意不能假设 $x\in X$ 的逆元存在。

### 算法

适当取 $m$，用 $T = \{x^it\mid 1\leq i \leq m\}$ 定义子集 $T\subset S$。用哈希表管理 $T$ 的元素。

若 $x^ns=t$，则对任意 $i$ 有 $x^{n+i}s = x^i t$，因此注意对 $k = \lceil (n+1) / m\rceil$ 有 $x^{km}s \in T$。

先求使 $x^{km}s \in T$ 的最小 $k$。这通过对 $s$ 不断作用 $x^m$ 来算。由 $k$ 的最小性，若 $n < (k-1)m$ 则 $x^ns\neq t$。对 $(k-1)m\leq n < km$ 的范围全搜索，若存在满足 $n < km$ 的解，则得到其中最小的解。

$x^ns = t$ 的 $n$ 存在、但用上面方法求不到解的，是如下图的状况。考虑以 $S$ 为顶点集、从 $s$ 向 $xs$ 连有向边得到的 functional graph。

由 $x^{km}s = x^it$ 可知能到达 $t$，所以 $t$ 是环上的点。因此 $x^{km}s = x^it$ 也是环上的点。

这种情形下，求使 $x^{lm}s \in T$ 的最小 $k<l$。若不存在这样的 $l$，则无解。取这样的 $l$ 时，由 $x^{km}s$ 在环上可知，必存在满足 $(l-1)m\leq n< lm$ 且 $x^ns = t$ 的 $n$。又由 $l$ 的最小性，不存在满足 $n < (l-1)m$ 的解。因此全搜索 $(l-1)m \leq n < lm$ 就得到解。

注意上面的讨论以“$x^ns=t$ 的 $n$ 存在”为前提（$t$ 不在环上的情形下，不存在满足 $(l-1)m\leq n < lm$ 的 $n$）。

综上得到如下算法。探索范围请配合约束 $n < N$ 适当确定：

- 预计算 $T = \{x^it\mid 1\leq i \leq m\}$ 的哈希值。
- 计算 $x^m$。
- 对 $k = 1, 2, 3, \ldots$ 依次检查 $x^{km}s \in T$ 是否成立。
- 对使 $x^{km}s\in T$ 的 $k$，检查 $(k-1)m\leq n < km$ 中的 $n$ 是否满足 $x^ns=t$。若找到这样的 $n$，它就是所求。另外，若这种全搜索失败 2 次，则无解。

由于 $n$ 的全搜索至多进行 2 次，上面的算法达到期望时间复杂度 $O\Bigl(m + \frac{N}{m}\Bigr)$。例如取 $m = \lfloor\sqrt{N}\rfloor$，则期望时间 $O(\sqrt{N})$。

若适当实现，算法中出现的计算次数更详细如下：

- 幺半群元素的积的计算：$O(\log N)$ 次
- 把幺半群元素作用到集合的计算：$O(\sqrt{N})$ 次

幺半群元素的积与作用的复杂度不同时，留意这一点的实现或许能改善复杂度（例如 $X$ 为全体 $n\times n$ 矩阵、$S$ 为全体 $n$ 元列向量的情形等）。
