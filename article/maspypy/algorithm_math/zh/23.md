## 最大公约数（ユークリッドの互除 / gcd の計算）

计算 $x,y$ 的最大公约数 $\mathrm{gcd}(x,y)$（最大公约数英语为 greatest common divisor，故略为 gcd）。

另外 $x=y=0$ 时，任意整数都是 $x,y$ 的公约数。故公约数最大值不存在，$\mathrm{gcd}(0,0)$ 通常不定（从理想论视角，也有定义为 $0$ 的）。

### 数学背景

$d$ 整除 $n$ 时写 $d\mid n$。成立：
$$
d\mid x \text{ 且 } d\mid y \iff d\mid x \text{ 且 } d\mid x – ky
$$
这由 $d$ 的倍数间和・差仍是 $d$ 的倍数简单证得。进一步由此定理知 $\mathrm{gcd}$ 的性质 $\mathrm{gcd}(x,y) = \mathrm{gcd}(x, y-kx)$ 成立。利用此，可如下算 $2$ 数的最大公约数：
$$
\mathrm{gcd}(345,100) = \mathrm{gcd}(100,45) = \mathrm{gcd}(45,10) = \mathrm{gcd}(10,5) = \mathrm{gcd}(5,0) = 5.
$$
此计算方法称 Euclid 的互除法。反复把大数替换为被小数除的余数。

### 复杂度

设 $a>b>0$，且 $a$ 被 $b$ 除的余数为 $c$。由
$$
a \geq 2b \implies b+c \leq b+b \leq \frac23(a+b),\qquad
a \leq 2b \implies b+c \leq b+(a-b) \leq \frac23(a+b)
$$
知 Euclid 互除法推进 $1$ 步，两数之和变为 $\frac23$ 倍以下。因此 $\gcd(x,y)$ 计算在 $O(\log(x+y))$ 可做。因第一次除法两者都降到 $\min(x,y)$ 以下，也可 $O(\log \min(x,y))$。（由上证明，计算次数上界可评价为 $\log_{1.5}(x+y)$，此底 $1.5$ 精密化可改善到黄金比 $\frac{1+\sqrt{5}}{2} = 1.618$。）

我们熟悉的 $2, 3$ 位整数，由质因数求最大公约数看似简洁，但位数变大时 Euclid 互除法性能压倒性高，计算机连数百位数的 gcd 都能瞬时算。

### 实现

gcd 函数在 math・numpy 等库也有，但这里自做一个。

```
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
```

```
def gcd(a, b):
    return gcd(b, a % b) if b else a
```

举了循环实现、递归实现 $2$ 种，但处理内容相同。另外函数调用开销部分，循环实现性能更好。（若函数单次处理足够重，调用负担相对可忽略，但本次只做 $1$ 次除法，故调用差异相对多。性能另文打算处理测量结果等。）

### 相关：最小公倍数

$2$ 数 $a,b$ 的最小公倍数写为 $\mathrm{lcm}(a,b)$（least common multiple）。与 $\mathrm{gcd}$ 间有如下关系：
$$ \mathrm{lcm}(a,b) = \frac{ab}{\mathrm{gcd}(a,b)}.$$
这由考虑质因数分解证得（$3$ 数以上的最大公约数・最小公倍数间无此关系）。

因此 $\mathrm{lcm}(a,b)$ 也能 $O(\log(a+b))$ 算。

```
def lcm(a,b):
    return a // gcd(a,b) * b
```

gcd 当然是 $a,b$ 的约数，故能在积之前插入除法。特别处理 64 位整数等时，先取积（即使最小公倍数在 64 位整数范围内可取）也可能溢出。

### 相关：ax+by=d 的整数解

当 $d = \mathrm{gcd}(a,b)$，由 Euclid 互除法能算 $ax + by = d$ 的解之一。这高中数学也常涉及。也称“扩展互除法”。

```
def extgcd(a, b):
    """
    返回使 ax + by = gcd(a,b) = d 成立的 (x,y,d)
    """
    if b == 0:
        return (1, 0, a)
    q, r = a // b, a % b
    x, y, d = extgcd(b, r)
    s, t = y, x - q * y
    return s, t, d
```

实现时，能否正确写 $s, t$ 的式是要点。这里考虑

- 给定使 $bx + ry = d$ 成立的 $x,y$，求使 $(qb+r)s + bt = d$ 成立的 $s,t$

即可。由系数比较令 $x = qs + t$ 且 $y = s$ 成立即可，故如上实现。另外 $x,y$ 可能返回负数（一般一方正一方负），依用途注意返回值处理。

### 相关：a mod N 的逆元

$a,N$ 为整数且 $\mathrm{gcd}(a,N) = 1$ 时，使 $ax \equiv 1\pmod{N}$ 的 $x$ 称为 $a\bmod N$ 的逆元。如上，由 Euclid 互除法能算满足 $ax + Ny = 1$ 的整数 $(x,y)$。此 $x$ 当然满足 $ax\equiv 1\pmod{N}$，故这就是逆元。不想要 $x < 0$ 时，负数则加 $N$ 的处理即可。

```
def inv_mod(a, N):
    """
    返回使 ax = 1 mod N 的 x
    """
    return extgcd(a, N)[0]
```

另外 $N$ 为素数时，由 Fermat 小定理可用 $a^{N-2} \bmod N$ 算 $a$ 的逆元。设 $a < N$，互除法计算量 $O(\log a)$、Fermat 小定理方法 $O(\log N)$。几乎无需区分用，但只对付小 $a$ 时互除法计算量更少（应用上，需要算的不是单一 $a$ 而是 $1$ 以上 $n$ 以下所有 $a$ 的逆元时，也能 $O(n)$ 算）。

### 相关：中国剩余定理

设 $a_1$, $a_2$ 为整数，$m_1$, $m_2$ 为互素整数。此时满足
$$ x \equiv a_1\pmod{m_1},\qquad x\equiv a_2\pmod{m_2} $$
的整数 $x$ 在 $\bmod m_1m_2$ 下唯一确定。这称中国剩余定理。

来算 $x$。满足第 1 条件的 $x$ 可写 $x = a_1 + m_1y$。巧妙调 $y$ 使 $x\equiv a_2\pmod{m_2}$ 成立。
$$ x \equiv a_2\pmod{m_2} \iff a_1 + m_1y\equiv a_2\pmod{m_2} \iff m_1y\equiv a_2-a_1\pmod{m_2} $$
故若 $m_1 \bmod m_2$ 的逆元为 $z$，则 $y = (a_2 – a_1)z$ 满足条件。

```
def CRT(a_1, a_2, m_1, m_2):
    """
    返回满足 x = a_1 mod m_1, x = a_2 mod m_2 的 x
    """
    y = (a_2 - a_1) * inv_mod(m_1, m_2) % m_2
    return a_1 + m_1 * y
```
