## 基于分割统制的静态数列区间积查询（分割統治による静的列の区間積クエリ）

### 概要

本篇处理如下形式的问题。

设 $X$ 为幺半群，$(x_0, \ldots, x_{N-1})$ 为 $X$ 的元素的数列。回答 $Q$ 个如下形式的查询：给定区间 $[a,b)$，求 $\prod_{a\leq i < b} x_i$（下标升序的总积 $x_a\cdots x_{b-1}$）。

不过，数列是静态的、查询是离线的。即 $x_i$ 在问题中固定，查询 $(a,b)$ 全部一起给出，以任意顺序求答案即可。

以下为简单起见，假设所有查询区间 $[a,b)$ 满足 $b-a\geq 2$。注意依实现可能需对长度为 $1$ 的查询分类处理。另外，除非特别说明，假设幺半群两个元素的积的计算量为 $O(1)$。但文章一部分也关注这不成立的情形。

文章后半关于特殊情形下复杂度改善的内容，因为没见过，所以写成文章。前半感觉是熟知的，但想不起具体资料，所以这里也解说。

### 基于分割统制的解法

设 `dfs(L,R)` 为回答所有满足 $[a,b) \subset [L, R)$ 的查询 $(a,b)$ 的函数，可如下设计：

```
def dfs(L, R):
    M = (L + R) // 2
    [ 计算满足 a < M 且 M < b 的查询的答案 ]
    dfs(L, M), dfs(M, R)
```

其中答案的计算，利用 $a < M < b$ 时有

$$\prod_{a\leq i < b} x_i = \biggl(\prod_{a\leq i < M}x_i\biggr)\biggl(\prod_{M\leq i < b}x_i\biggr)$$

可知：预计算

- 各 $L\leq a < M$ 对应的 $\prod_{a\leq i < M} x_i$
- 各 $M < b \leq R$ 对应的 $\prod_{M\leq i < b} x_i$

之后，对每个查询用 1 次幺半群积就能算出答案。从 $M$ 开始向 $L, R$ 计算累积积，这个预计算可用 $R-L$ 次幺半群积算得。由此可知，本问题可用 $O(N\log N + Q)$ 次幺半群积的解法解出。

| 解法 | 幺半群积次数 | 空间复杂度 |
|---|---|---|
| 分割统制 | $O(N\log N + Q)$ | $O(N+Q)$ |

实现例：https://judge.yosupo.jp/submission/125324

上面的实现中，为获取各 $[L,R)$ 内要计算的查询又花了 $O(Q\log N)$ 时间，所以复杂度为 $O((N+Q)\log N)$。用桶排序等适当处理查询，可使复杂度为 $O(N\log N + Q)$ 时间，但省略这种实现的说明。

以下“基于分割统制的解法”即指这种方法。从上面的实现例抽出主要部分如下：

```
  auto calc = [&](int L, int M, int R, vector<T>& query) -> void {
    static vector<int> dp(N + 1);
    // 累积积的计算
    dp[M] = unit;
    for (int i = M; i > L; --i) dp[i - 1] = op(A[i - 1], dp[i]);
    for (int i = M; i < R; ++i) dp[i + 1] = op(dp[i], A[i]);
    // 答的计算
    for (auto [q, a, b]: query) ANS[q] = op(dp[a], dp[b]);
  };

  auto dfs = [&](auto& dfs, int L, int R, vector<T>& query) -> void {
    if (R - L <= 1) {
      for (auto&& [q, a, b]: query) ANS[q] = A[a];
      return;
    }
    int M = (L + R) / 2;
    vector<T> query_L, query_R, other;
    for (auto&& [q, a, b]: query) {
      if (b <= M) query_L.emplace_back(q, a, b);
      if (M <= a) query_R.emplace_back(q, a, b);
      if (a < M && M < b) other.emplace_back(q, a, b);
    }
    calc(L, M, R, other), dfs(dfs, L, M, query_L), dfs(dfs, M, R, query_R);
  };
  dfs(dfs, 0, N, query);
```

### 与线段树的比较

线段树例如在 我的文章 中有解说。比较基于分割统制的解法与基于线段树的解法。

| 解法 | 幺半群积次数 | 空间复杂度 |
|---|---|---|
| 分割统制 | $O(N\log N + Q)$ | $O(N + Q)$ |
| 线段树 | $O(N + Q\log N)$ | $O(N)$ |

竞技编程中常有 $N, Q$ 同阶的情形，在这种情形下可知分割统制解法与线段树解法的时间・空间复杂度同阶。另外，分割统制解法有“数列静态且查询离线”的约束，一眼看去似乎分割统制解法优点少。

但是，在如下情形时，分割统制可能比线段树好很多：

- “两个幺半群元素的积”比“幺半群元素与 $x_i$ 的积”算得更快的情形

回顾分割统制解法，进行了如下次数的两种幺半群积：

- 幺半群元素乘 $x_i$ 的操作：$O(N\log N)$ 次
- 两个幺半群元素相乘的操作：$O(Q)$ 次

基于线段树的解法则为：

- 两个幺半群元素相乘的操作：$O(N + Q\log N)$ 次

因此，若“任意两个幺半群元素相乘”比“幺半群元素乘 $x_i$”的计算量大，则分割统制解法可能减少复杂度。例如有如下例子：

**问题例 1**（点击展开）

幺半群是次数低于 $K$ 的多项式全体（运算为 $\pmod{1-x^K}$ 下的积），且 $x_i = 1 + x^{A_i}$。任意两个幺半群元素相乘是 $O(K^2)$ 时间或利用 FFT 的 $O(K\log K)$ 时间，但乘 $x_i$ 的操作可 $O(K)$ 时间完成。注意，求查询答案处需要“任意幺半群积”型的计算，但答案计算只需要积常数项，所以这里也能 $O(K)$ 时间完成。整体可在 $O((N\log N + Q)K)$ 时间解出。

### 与 disjoint sparse table 的比较

disjoint sparse table（以下 DST）请参考 noshi91 さん的文章 等。与线段树时同样比较。

| 解法 | 幺半群积次数 | 空间复杂度 |
|---|---|---|
| 分割统制 | $O(N\log N + Q)$ | $O(N+Q)$ |
| DST | $O(N\log N + Q)$ | $O(N\log N)$ |

其实基于分割统制的解法与基于 DST 的解法几乎相同。更详细地说，可理解为：把分割统制解法中出现的向左右方向的累积积全部预计算，就是 DST。（不过一般 DST 实现中，会把分割 $[L,R)$ 的位置不取中点而取能被 $2$ 整除次数最多的位置等，以使所需预计算能用位运算方便访问。）

主要区别在是否把所有累积积放进内存，因此 DST 空间复杂度增大，但能处理在线查询，各有缺点・优点。

关于两种幺半群积“任意积”“与 $x_i$ 的积”的事项，分割统制与 DST 没有特别区别。

### 分割统制的剪枝

给分割统制的实现加上简单的剪枝。在累积积的预计算中，只计算查询到达的地方。具体实现例上，上面举的实现例几乎只加几行。

```
  auto calc = [&](int L, int M, int R, vector<T>& query) -> void {
    static vector<int> dp(N + 1);
    int min_a = M, max_b = M;
    for (auto&& [q, a, b]: query) min_a = min(min_a, a), max_b = max(max_b, b);

    // 累积积的计算
    dp[M] = unit;
    for (int i = M; i > min_a; --i) dp[i - 1] = op(A[i - 1], dp[i]);
    for (int i = M; i < max_b; ++i) dp[i + 1] = op(dp[i], A[i]);
    // 答的计算
    for (auto [q, a, b]: query) ANS[q] = op(dp[a], dp[b]);
  };
```

在幺半群积较慢等时，是个轻松的常数倍加速。

### 剪枝带来的复杂度阶改善

查询区间有特殊的约束时，实现了剪枝的分割统制解法有时能改善复杂度阶。

#### 查询区间长度几乎为常数的情形

为简单起见，先假设查询区间长度为常数。即存在常数 $K$ 使所有查询区间 $[a,b)$ 满足 $b-a=K$。

这种情形下，要预计算的 $[L,R)$ 个数为 $O(N/K)$ 个，每个 $[L,R)$ 的预计算可在 $O(K)$ 时间完成，因此查询用的预计算（累积积的计算）变为 $O(N)$ 次。

| 解法 | 幺半群积次数 | 空间复杂度 |
|---|---|---|
| 分割统制 | $O(N\log N + Q)$ | $O(N+Q)$ |
| 分割统制（剪枝・特殊约束） | $O(N + Q)$ | $O(N+Q)$ |

$O(N+Q)$ 时间比用线段树或 DST 更好。不过这种情形用 SWAG 也能实现 $O(N+Q)$ 时间，连同两种幺半群积的事项也是同样复杂度。

为简单起见以“查询区间长度为常数”叙述了复杂度改善，但用同样方法，当查询区间长度的最大值・最小值之比被常数控制时也能达到 $O(N+Q)$ 时间。例如对某 $K$ 所有查询区间 $[a,b)$ 满足 $K\leq b-a \leq 2K$ 的情形。

#### 查询区间单调的情形

查询区间的列 $\{[a_q, b_q)\}$ 单调，是指取出的左端列 $\{a_q\}$ 与右端列 $\{b_q\}$ 都单调递增。这种情形累积积的计算也变为 $O(N)$ 次。

| 解法 | 幺半群积次数 | 空间复杂度 |
|---|---|---|
| 分割统制 | $O(N\log N + Q)$ | $O(N + Q)$ |
| 分割统制（剪枝・特殊约束） | $O(N + Q)$ | $O(N + Q)$ |

证明写起来麻烦，所以暂且参考如下推文及其回复。

> これ区間がqueue(l,rが単調増加)形のときO(N logN)のケース作れるのかな
> — よすぽ (@yosupot) February 10, 2023

> 再帰のある段階において左向きの累積和を L 個計算したいとして、L > X なる最大の 2 冪 X を持ってきて、X 個計算するものとしても計算量のオーダーは変わらない。このときどの要素も計算のために参照される回数が 1 回以下になるので、O(n)。
> — 熨斗袋 (@noshi91) February 10, 2023

我觉得证明了是 $O(N)$。

想证的事：从 $m$ 向左右伸出的长度总和为 $O(N)$。

大概可设 $N = 2^n$，证其不超过 $4N$。

伸出长度 $x$ 时，取满足 $2^k < x \leq 2^{k+1}$ 的 $k$，改为伸出长度 $2^k$。此设定下证其不超过 $2N$。
— maspy (@maspy_stars) February 10, 2023

我的证明与 noshi さん的证明说的是同一件事。

要说明累积积的计算整体 $O(N)$ 时间，只需说明各元素在累积积的计算中只出现 $O(1)$ 次即可，但这不成立。不过若适当定义累积积计算的 heavy part 之类（$N$ 为 $2$ 的幂时，取比取累积积的部分更小的最大 $2$ 的幂的长度），则可证任何元素在左向・右向的 heavy part 中至多出现 1 次。因此 heavy part 的长度总和不超过 $2N$，从而取累积积的部分的长度总和不超过 $4N$。

$N$ 不为 $2$ 的幂时，把取累积积的部分中所含最大的 $[l, M)$ 形子节点区间定义为 heavy part 等，也能做同样讨论。

也收到了归纳法的证明。

> 传达归纳法方针。只评估左向累积和的计算量，设 $f(l, r)$ 的计算量，对满足 $l < a \leq b < r$ 的查询 $[a, b)$ 中 $a$ 的最大值记为 amax，则被 $(r – l) + (amax – l)$ 的常数倍控制。按 amax 与 $(l+r)/2$ 的大小分类即可证。
> — 熨斗袋 (@noshi91) February 10, 2023
