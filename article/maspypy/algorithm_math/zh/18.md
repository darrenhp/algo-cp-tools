### 概要

处理 monoid 的数列。能进行 1 点更新、区间积获取的 Segment Tree。

所谓非递归实现

当作获取性能的手段来学，结果反而觉得这样更易懂。

1-based index

不假设 $N=2^n$

意外地文献少，自己画图前都不太能接受。

Segment Tree 文献丰富，但这边的条件也散乱、想细究的微妙没全齐（或前提了交换律、或没有实现解说等），为加深理解需在文献间游荡，花了时间。为自己也整理一次。

写 $x_i$ 等则是 monoid $X$ 的元素。给定 $X$ 的元素列 $[x_0,x_1,\ldots,x_{N-1}]$ 时，处理

- 改变 $x_i$ 的值
- 计算 $\prod_{L\leq i < R} x_i$

的 Segment Tree。边观察实现，特别在具体值上仔细可视化算法，目标是获得能立刻从 $0$ 实现的老练理解。

### 实现・可视化

我的实现例：https://judge.yosupo.jp/submission/7795

首先以 $N = 8$ 来做。

#### 初始化

```
def build(self, seq):
    for i, x in enumerate(seq, self.N):
        self.X[i] = x
    for i in range(self.N - 1, 0, -1):
        self.X[i] = self.X_f(self.X[i << 1], self.X[i << 1 | 1])
```

实际数据放在下标 $[N, 2N)$ 部分。设下标 $i$ 处数据为 $x_i$ 时，使 $x_i = x_{2i}x_{2i+1}$ 成立。可从后往前顺序算。

#### 1 点更新

```
def set_val(self, i, x):
    i += self.N
    self.X[i] = x
    while i > 1:
        i >>= 1
        self.X[i] = self.X_f(self.X[i << 1], self.X[i << 1 | 1])
```

改写最下段适当位置，就此往上。对含某元素的区间，把下标不断除以 $2$ 即可迁移。

#### 区间获取

```
def fold(self, L, R):
    L += self.N
    R += self.N
    vL = self.X_unit
    vR = self.X_unit
    while L < R:
        if L & 1:
            vL = self.X_f(vL, self.X[L])
            L += 1
        if R & 1:
            R -= 1
            vR = self.X_f(self.X[R], vR)
        L >>= 1
        R >>= 1
    return self.X_f(vL, vR)
```

所谓非递归实现，是从外侧算进来。除“左侧已算的积、右侧已算的积”外，还持有“未计算的区间 $x_L,\ldots,x_{R-1}$”来循环。

$L$ 为奇数时当场算 $x_L$，$R-1$ 为偶数时当场算 $x_{R-1}$。其余部分两个两个的积已汇总进同一父节点，故把计算委让到上一段。虽没意识到，最终是左起奇数编号、右起偶数编号的 $x_i$ 被乘起来呢。

不假设交换律的实现中，注意积的顺序。例如上例中注意别把右侧积变成 $x_{14}x_6$。

若假设交换律，则无需分左右持有计算过程，按喜欢的顺序从喜欢的方向不断追加到计算结果即可。

#### 不假设 $N=2^n$ 的情形

其实完全相同的代码就能动。初听时很惊讶。例如以 $N=11$ 画图。

上面的图见过，但觉得下面的图更适合理解（个人差异？）。

像至今那样，按 $x_i = x_{2i}x_{2i+1}$ 的规则填。填满所有格，但此时一部分 $x_i$ 会进不对应区间积的异常值（$x_{5}=x_{20}x_{21}x_{11}$ 等）。但这些值不被用于计算，所以其实不会坏。

回想区间积的计算。只是从最下段起，孤立的两端计算。两个两个能汇总的区间归约到上一段。虽说会产生一部分进异常值的地方，但两个两个汇总、其上正常值所在处的上方也进正常值，所以区间积计算正常运作。

### 顺便

$x_1 = x_{16}x_{17}x_{18}x_{19}x_{20}x_{21}x_{11}x_{12}x_{13}x_{14}x_{15}$ 呢。

无论 $N$ 如何，$x_1$ 都这样进全体元素的积。不过因积的顺序坏了，是异常值之类。

但若说可交换 monoid，则 $x_1$ 成为正常的全体元素积。记住的话，或许常有用？
