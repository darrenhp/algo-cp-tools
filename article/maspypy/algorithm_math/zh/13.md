## Dirichlet 级数与 Dirichlet 积（Dirichlet 級数と Dirichlet 積）

### Dirichlet 级数与 Dirichlet 积

定义域为 $\N = \{1,2,3,\ldots\}$ 的函数 $a, b\colon \N\longrightarrow \C$ 称为数论函数（arithmetic function）。

由 $c(n) = \sum_{ij=n}a(i)b(j)$ 确定的 $c\colon \N\longrightarrow \C$ 称为 $a, b$ 的 Dirichlet 积。本文记 $c = a * b$。这个积满足交换律、结合律、分配律等。

也可以说是关于幺半群 $(\N, \times)$ 的卷积运算。$(\N\cup\{0\}, +)$ 的卷积运算，换成形式幂级数后往往能看清性质；而 $(\N, \times)$ 的情形，一般用 Dirichlet 级数表示。也就是把数列 $\{a_n\}$ 换成

$$D_a(s) = \sum_{n=1}^{\infty} a_nn^{-s}$$

这样，Dirichlet 积就转换为级数的积：$c = a * b \iff D_c = D_aD_b$。

由 $i^{-s}\cdot j^{-s} = (ij)^{-s}$ 并扩张使之满足分配律来定义积。有时会考虑代入 $\text{Re}(s)$ 充分大的复数 $s$，但这次忽略收敛性等细节。

“$-s$”的符号是历史背景造成的，本文中并不重要。若嫌写式麻烦，全部换成“$+s$”也不会出问题。

另外虽用无穷数列来形式化，但基本处理是只把 $1\leq n\leq N$ 部分作为数组持有。

### Dirichlet 积的计算量

已知 $a$, $b$ 求 $c = a*b$ 时，计算 $c(1), \ldots, c(N)$ 可在 $O(N\log N)$ 时间内完成。要领如下：

```
c = [0] * (N+1)
for i in range(1, N+1):
  for j in range(1, N//i+1):
    c[i*j] += a[i] * b[j]
```

### 积性 Dirichlet 级数的情形

满足 $a(1) = 1$，且对互素的 $n,m$ 有 $a(nm) = a(n)a(m)$ 的 $a$ 称为积性的。由素数幂处的值 $a(p^k)$ 能还原所有 $a(n)$ 这一性质，使得约数个数、约数和、Euler 函数等是著名例子。

用 Dirichlet 级数的话说，对应于级数具有 Euler 乘积分解 $$D_a(s) = \prod_p \Bigl(\sum_{k}a(p^k)p^{-ks}\Bigr)$$。

#### $O(N\log\log N)$ 时间计算

$a$ 为积性时，$a*b$ 的计算可在 $O(N\log\log N)$ 时间内完成。利用 $a$ 被分解为稀疏函数的 Euler 乘积，反复做 in-place 的 $p$ 部分乘法。用 Dirichlet 积的话说，如下计算即可：

```
for p in primes:
  D_{a,p}(s) = sum a(p^k) p^{-ks}  (p-part of D_a)
  D_b(s) ← D_b(s) D_{a,p}(s)
```

具体：

```
c = b
for p in primes:
  for i in range(N//p, 0, -1):
    n = p * i
    # n = (p^k) * m 时，c[n] ← c[n] + a[p^k] * c[m] 更新
    q, m = p, i
    while True:
      c[n] += a[q] * c[m]
      if m % p != 0:
        break
      q, m = q * p, m // p
```

由于是 in-place 更新，要注意更新顺序。从大编号开始更新，以避免后续计算需要的部分被先覆盖。复杂度可分析为 $$\sum_{q=p^k\leq N}\Bigl\lfloor\frac{N}{q}\Bigr\rfloor=\sum_{p\leq N} \Bigl\lfloor\frac{N}{p}\Bigr\rfloor + O(N) = O(N\log\log N)$$（$q$ 为素数幂，$p$ 为素数）。

#### $O(N)$ 时间计算

当 $c$ 为积性时（特别地 $a, b$ 为积性时），若 $n$ 恰被素数 $p$ 整除 $k$ 次，即 $n = p^km$，则 $c(n) = c(p^k)c(m)$。利用此可对 $c(1), \ldots, c(N)$ 在 $O(N)$ 时间计算。

- 对素数幂 $p^k\leq N$，愚直地（$O(k^2)$ 时间）计算 $c(p^k)$。
- 对 $n = 2, 3, 4, \ldots$ 顺序，若不是素数幂，则令 $n = p^km$，由 $c(n) = c(p^k)c(m)$ 求得 $c(n)$。

需要预处理：持有整除各 $n$ 的 $p^k$。该预处理也可用线性筛在 $O(N)$ 时间内完成。

### Dirichlet 积与累积和

对数论函数 $a$，记 $A(n) = \sum_{i=1}^n a(i)$。本文以小写与大写对应，$a$ 的累积和记为 $A$，$b$ 的累积和记为 $B$，$c$ 的累积和记为 $C$。

首先确认以下。

**【命題 1】** 设 $c = a*b$，且对任意 $1\leq i\leq N$ 已算出 $a(i), b(i), A(i), B(i)$。则 $C(N)$ 可在 $O(\sqrt{N})$ 时间算出。

由 $C(N) = \sum_{n=1}^N \sum_{ij=n}a(i)b(j) = \sum_{ij\leq N}a(i)b(j)$ 变形。再令 $M = \lfloor \sqrt{N}\rfloor$，将 $\sum_{i,j}$ 变形为 $\sum_{i\leq M} + \sum_{i > M}$。

固定 $i \leq M$。由 $ij\leq N\iff j\leq \lfloor N/i\rfloor$，这部分可算作 $a(i)B(\lfloor N/i\rfloor)$。

当 $i > M$ 时，必须有 $j \leq M$。固定 $j$ 时，$i$ 的范围为 $M < i \leq \lfloor N/j\rfloor$，故 $b(j)\bigl(A(\lfloor N/j\rfloor) – A(M)\bigr)$ 就是固定 $j$ 的贡献。

累加这些，$C(N)$ 可在 $O(\sqrt{N})$ 时间算出。

$N$ 很大时，此计算中需要的 $a(i), b(i), A(i), B(i)$ 的下标相当稀疏（sparse）。再令 $M = \lfloor \sqrt{N}\rfloor$。

**【命題 2】** 设 $c = a*b$，且以下形式的值都已算出：

- 对 $1\leq i\leq M$ 的 $a(i), b(i)$
- 对 $1\leq i\leq M$ 的 $A(\lfloor N/i\rfloor)$, $B(\lfloor N/i\rfloor)$

则 $C(N)$ 可在 $O(\sqrt{N})$ 时间算出。

计算方法完全相同。再同样做下去，可得如下。

**【命題 3】** 设 $c = a*b$，且以下形式的值都已算出：

- 对 $1\leq i\leq M$ 的 $a(i), b(i)$
- 对 $1\leq i\leq M$ 的 $A(\lfloor N/i\rfloor)$, $B(\lfloor N/i\rfloor)$

则以下所有值在合计 $O(N^{3/4})$ 时间内可算：

- 对 $1\leq i\leq M$ 的 $c(i)$
- 对 $1\leq i\leq M$ 的 $C(\lfloor N/i\rfloor)$

计算前后统一数据的持有方式，以便反复进行同样的计算。算法几乎不变。

对可写成 $n = \lfloor N/i\rfloor$ 的 $n$，需要 $A(\lfloor n/j\rfloor)$ 这样的值，但由 $\lfloor n/j\rfloor = \lfloor N/ij\rfloor$ 成立，结果计算中处处只出现可写成 $\lfloor N/i\rfloor$ 的下标。$A(1), \ldots, A(M)$ 的值新被需要，但作为 $a(i)$ 的累积和很容易得到。

确认复杂度：

- 计算 $c(1), \ldots, c(M)$ 需 $O(M\log M) = O(N^{1/2}\log N)$ 时间
- 各 $C(\lfloor N/i\rfloor)$ 的计算，对每个 $i$ 需 $O(\sqrt{N/i})$ 时间

由 $\int_{1}^M\frac{1}{\sqrt{t}}dt = O(\sqrt{M})$ 等估计，可知合计为 $O(N^{3/4})$ 时间。

用 $\sqrt{n}$ 分段，自然得到 $O(N^{3/4})$ 这个复杂度，但其实这个复杂度还能轻松降下来。

**【命題 4】** 取 $K, L$ 使 $N\leq KL$。设 $c = a*b$，且以下形式的值都已算出：

- 对 $1\leq i\leq K$ 的 $a(i), b(i)$
- 对 $1\leq i\leq L$ 的 $A(\lfloor N/i\rfloor)$, $B(\lfloor N/i\rfloor)$

则以下所有值在合计 $O(K\log K + (NL)^{1/2})$ 时间内可算：

- 对 $1\leq i\leq K$ 的 $c(i)$
- 对 $1\leq i\leq L$ 的 $C(\lfloor N/i\rfloor)$

特别地，取 $K = \lceil (N/\log N)^{2/3}\rceil$, $L = \lceil N^{1/3}(\log N)^{2/3}\rceil$ 时，为 $O(N^{2/3}(\log N)^{1/3})$ 时间。

另外，此时间复杂度在下列条件下可进一步缩减：

- 若 $a, b$ 中一方为积性，则 $O(N^{2/3}(\log \log N)^{1/3})$ 时间
- 若 $a, b$ 双方都积性，则 $O(N^{2/3})$ 时间

单算一个 $C(N)$ 时以 $N^{1/2}$ 分段是最优阶，但算很多值时，以 $N^{2/3}$ 程度分段能改善阶。

算法同样：

- 计算 $c(1), \ldots, c(K)$ 需 $O(K\log K)$ 时间。
- 计算 $A(1), \ldots, A(K)$ 以及 $B(1), \ldots, B(K)$ 需 $O(K)$ 时间。
- 对每个 $1\leq i\leq L$，用（【命題 2】）$O(\sqrt{N/i})$ 时间计算 $C(\lfloor N/i\rfloor)$。对 $1\leq i\leq L$ 的合计时间为 $O((NL)^{1/2})$ 时间。

于是可知为 $O(K\log K + (NL)^{1/2})$ 时间。

另外若 $a, b$ 都积性，则 Dirichlet 积计算更快，可知上面整体为 $O(K + (NL)^{1/2})$ 时间。此情形取 $K = \lceil N^{2/3}\rceil$, $L = \lceil N^{1/3}\rceil$ 即可实现 $O(N^{2/3})$ 时间。

### 除法的计算

巧妙地回推同样的讨论，可知如下操作也可做。需要 $a_1\neq 0$。

**【命題 5】** 取 $K, L$ 使 $N\leq KL$。设 $a*b = c$，且以下形式的值都已算出：

- 对 $1\leq i\leq K$ 的 $a(i), c(i)$
- 对 $1\leq i\leq L$ 的 $A(\lfloor N/i\rfloor)$, $C(\lfloor N/i\rfloor)$

则以下所有值在合计 $O(K\log K + (NL)^{1/2})$ 时间内可算：

- 对 $1\leq i\leq K$ 的 $b(i)$
- 对 $1\leq i\leq L$ 的 $B(\lfloor N/i\rfloor)$

特别地，取 $K = \lceil (N/\log N)^{2/3}\rceil$, $L = \lceil N^{1/3}(\log N)^{2/3}\rceil$ 时，为 $O(N^{2/3}(\log N)^{1/3})$ 时间。

另外，此时间复杂度在下列条件下可进一步缩减：

- 若 $a, c$ 中一方为积性，则 $O(N^{2/3}(\log \log N)^{1/3})$ 时间
- 若 $a, c$ 双方都积性，则 $O(N^{2/3})$ 时间

这是【命題 4】的类似。利用【命題 1】中出现的式变形等，从小的 $b(i)$, $B(i)$ 开始顺序算。例如由 Dirichlet 积定义式可写 $$c(n) = a(1)b(n) + \text{更小 $b(i)$ 的贡献}$$ 从而可算 $b(1), b(2), \ldots, b(K)$。取累积和可得 $B(1), \ldots, B(K)$。由 $$C(n) = a(1)B(n) + \text{更小 $B(i)$ 的贡献}$$ 也可从小的（$i$ 大的）开始算 $B(\lfloor N/i\rfloor)$。

详细实现不介绍，请边解后述相关题边想细节。

【命題 2】的类似不成立。即只想要单点的值 $C(N)$ 时，算大的 $N$ 处的 $C(N)$ 也需要小的 $C(i)$ 的值，故复杂度为 $O(N^{2/3 + \epsilon})$ 形。

### 具体例子

代表性的 Dirichlet 级数有 $\zeta(s) = \sum_{n=1}^{\infty}n^{-s}$。另外它的平移 $\zeta(s-k) = \sum_{n=1}^{\infty}n^kn^{-s}$ 也常出现。仅这些的组合就能覆盖相当多的著名数论函数。

#### 约数函数的累积和

记 $\sigma_k(n) = \sum_{d|n} d^k$。特别地 $k=0$ 是约数个数，$k = 1$ 是约数和。Dirichlet 级数为

$$\sum_{n=1}^{\infty} \sigma_k(n)n^{-s} = \zeta(s)\zeta(s-k)$$

对 $\zeta(s)$ 或 $\zeta(s-k)$，把 $n$ 项看作常数时取第 $n$ 项、取前 $n$ 项累积和都可在 $O(1)$ 时间计算。因此它的前 $N$ 项总和由【命題 1】可在 $O(\sqrt{N})$ 时间算。

此例说到底只是计算 $\sum_{ij\leq N}i^k$，注意到至少一方在 $\sqrt{N}$ 以下去算而已，极为基本。对到目前为止的命题，想在简单情形复查逻辑时应该有用。

要枚举所有 $i$ 的 $\lfloor N/i\rfloor$ 项之前的总和时，由【命題 4】可在 $O(N^{2/3})$ 时间算。

#### Möbius 函数的累积和（Mertens 函数）

Möbius 函数 $\mu(n)$ 的累积和 $M(n) = \sum_{i=1}^n\mu(i)$ 称为 Mertens 函数。Möbius 函数在 Dirichlet 积中非常基本，相当于 $\zeta(s)$ 的逆元：$$\frac{1}{\zeta(s)} = \sum_{n=1}^{\infty}\mu(n)n^{-s}.$$

由【命題 5】可知 Mertens 函数 $M(N)$ 可在 $O(N^{2/3})$ 时间算出。

#### Euler 函数的累积和

对 Euler 函数 $\varphi(n)$，基本事实为：$n = \sum_{d|n}\varphi(d)$。即 $\zeta(s-1) = D_{\varphi}(s)\zeta(s)$ 成立。可知 $D_{\varphi}(s) = \frac{\zeta(s-1)}{\zeta(s)}$。

另外，此事也可由表示 $\varphi(n)$ 按质因数分解的计算法的 Euler 乘积 $$D_{\varphi}(s) = \prod_{p} (1 + (p-1)p^{-s} + (p^2-p)p^{-2s} + \cdots) = \prod_{p}\frac{1-p^{-s}}{1-p\cdot p^{-s}}$$ 验证。

对 $\zeta(s)$ 与 $\zeta(s-1)$ 应用【命題 5】，可知 $\sum_{i=1}^N \varphi(i)$ 可在 $O(N^{2/3})$ 时间算出。或者由 $D_{\varphi}(s) = \zeta(s-1)\cdot \frac{1}{\zeta(s)}$，用 Mertens 函数与【命題 4】也可。

#### 无平方数 (square-free number) 的计数

当不存在素数 $p$ 使 $p^2|n$ 时，称 $n$ 为无平方（square-free）。来计数不超过 $N$ 的无平方数。这就是求 Dirichlet 级数

$$f(s) = \prod_p (1 + p^{-s})$$

中 $n^{-s}$ 系数的累积和。由 $1 + p^{-s} = \frac{1-p^{-2s}}{1-p^{-s}}$ 得 $f(s) = \frac{\zeta(s)}{\zeta(2s)}$。于是 $f(s)\zeta(2s) = \zeta(s)$，所以若能以【命題 5】的形式管理 $\zeta(s)$ 或 $\zeta(2s)$ 即可。

$\zeta(2s)$ 只在平方数处有系数 $1$ 这一简单形式，故累积和作为平方数计数也容易做。因此，不超过 $N$ 的无平方数计数可在 $O(N^{2/3})$ 时间完成。

#### 稀疏的变形

也处理一个稍难的例。例如 $a(n) = \sigma_0(100n)$（$\sigma_0$ 为约数个数计数函数），求 $\sum_{n=1}^N a(n)$。

$\sigma_0(n)$ 与 $a(n)$ 可由 $n$ 的质因数分解计算。这说明 Dirichlet 级数 $D_{\sigma_0}$, $D_a$ 具有“Euler 乘积分解”。例如

- 令 $f_p(s) = 1 + 2p^{-s} + 3p^{-2s} + \cdots = \frac{1}{(1-X)^2}$（其中 $X = p^{-s}$），则 $D_{\sigma_0}(s) = \prod_{p} f_p(s)$

成立。$n$ 被 $p$ 整除 $k$ 次时乘上 $k + 1$ 这个计算步骤，对应项 $(k+1)p^{-ks}$。另外 $D_{\sigma_0}(s) = \zeta(s)^2$，利用该表示与 $\zeta(s) = \prod_p (1-p^{-s})^{-1}$ 也得同样结论。

$D_a$ 如何？$n$ 被 $p$ 整除 $k$ 次时的计算，对 $p\neq 2, 5$ 与 $\sigma_0$ 不变。因此 $D_a$ 可由 $D_{\varphi}$ 做稀疏变形来表示。

- 令 $g_2(s) = 3 + 4X + 5X^2 + 6X^3 + \cdots$（其中 $X = 2^{-s}$）
- 令 $g_5(s) = 3 + 4X + 5X^2 + 6X^3 + \cdots$（其中 $X = 5^{-s}$）

则 $D_a(n) = \prod_{p\neq 2, 5}f_p(s)\cdot g_2(s)\cdot g_5(s)$。

即 $D_{a}(s) = D_{\sigma_0}(s)\cdot \frac{g_2(s)g_5(s)}{f_2(s)f_5(s)}$。$F(s) = \frac{g_2(s)g_5(s)}{f_2(s)f_5(s)}$ 是非常稀疏的 Dirichlet 级数，只在 $n = 2^a5^b$ 处有非零值。

因此所有项的计算、累积和的计算都容易，$\sum_{n=1}^N \sigma_0(100n)$ 可在 $O(N^{2/3})$ 时间算。另外利用 $F$ 非常稀疏，可知 $\sigma_0$ 的累积和只需对形如 $n = \lfloor N/(2^a5^b) \rfloor$ 的 $n$ 进行，整体也可在 $O(\sqrt{N})$ 时间算。

作为“稀疏变形”，像这样少数素数部分的变形，或对所有 $p$ 在平方以上整除的数（powerful number）部分的变形，是典型例子。

### 问题例：Multiple Sequences (ARC 116 [C])

本文写作的直接契机就是此题。

C - Multiple Sequences（AtCoder）

适当替换记号，把 $A_i$ 换成比，可知它是如下题目：

记使自然数组 $(A_1, \ldots, A_M)$ 总积为 $n$ 的个数为 $f_M(n)$。求 $\sum_{n=1}^N f_M(n)$。

#### 解法 1：$O(N^{2/3}\log M)$ 时间解法

成立 $$\zeta(s)^M = \sum_{n=1}^{\infty} f_{M}(n)n^{-s}$$。即感兴趣的数列是 $\zeta$ 在 Dirichlet 积意义下 $M$ 次幂。

对 Dirichlet 级数，以【命題 4】的形式管理所需信息。$\zeta^i$ 总是积性的，故 Dirichlet 积计算每次 $O(N^{2/3})$ 时间。

若算 $M$ 次则复杂度糟糕，但 Dirichlet 积是结合的，故可用快速幂（重复平方），整体在 $O(N^{2/3}\log M)$ 时间算。

- 解答例：https://atcoder.jp/contests/arc116/submissions/21380847
- $O(N^{2/3}(\log N)^{1/3}\log M)$ 时间实现：https://atcoder.jp/contests/arc116/submissions/21380909
- $O(N^{2/3}(\log\log N)^{1/3}\log M)$ 时间实现：https://atcoder.jp/contests/arc116/submissions/21380909

在 AtCoder 代码测试环境，$N = M = 10^9$ 可在 3 秒算出。

#### 解法 2：$O(N^{2/3}\log N)$ 时间解法

记使 $2$ 以上的自然数组 $(A_1, \ldots, A_m)$ 总积为 $n$ 的个数为 $g_{m}(n)$。令 $G_m = \sum_{n=1}^Ng_{m}(n)$，则答案为 $\sum_{m}G_m\binom{M}{m}$。由 $2^m > N\implies G_m = 0$ 立即可知，只需对 $0\leq m\leq \log_2n$ 算 $G_m$。

这里成立 $\sum_{n=1}^{\infty}g_{m}(n)n^{-s} = (\zeta(s)-1)^m$。因为规则是“$2$ 以上的自然数”，用了 $\sum_{n\geq 2}n^{-s} = \zeta(s)-1$。

用二项式定理展开可知，只需算出对 $\zeta(s)^i$ ($0\leq i\leq \log_2 n$) 的 $N$ 项累积和。同样，把 $\zeta$ 一个个卷积上去即可。

- 解答例：https://atcoder.jp/contests/arc116/submissions/21380945（$O(N^{2/3}(\log\log N)^{1/3})$ 时间实现）

对 $N = M = 10^9$ 约 1 秒运行时间。与上法比更快，因为：

- 重复平方的乘法次数 $O(\log N)$ 次，比此解法的乘法次数 $O(\log M)$ 次常数倍更小
- 此解法的乘法对象始终是 $\zeta(s)$，故无需显式以数组持有它
