### 遇到的坑（已解决）
- `mcp__ardot__*` 必须经 DeferExecuteTool 调用。
- root frame 用 `layout:"none"` 不能 hug；改用固定大高度避免裁切。
- 代码/定理内 Frame 的 accent 条 `width:"fill_container"` + 内框 `height:"fill_container"` 循环依赖导致 0 高度 → 先显式高度，后改 `hug_contents`。
- capture_layout 的「text box extends beyond parent」多为误报（pre-wrap 估算偏差），以 capture_screenshot + problemsOnly 实际裁切为准。
- capture_screenshot 文件当前模型无法视觉解析 → 改用 capture_layout problemsOnly + 结构推理校验。
- SkillManage 工具不可用（仅 workbuddy_marketplace_skill 市场搜索/安装），无法保存自定义 skill。

### 本回合新增：正文内可点击链接 + 点击弹出预览弹窗
- **需求**：把正文里类似外链 URL 的文本变成可点击链接，点击后新开弹窗（链接预览）。
- **实现**：
  - 在 Desktop·浅色 `2:18` Content 的第 6 位（Section 1 段落后）插入「Inline Link Block」横向 WRAP 帧（`5:1`），内含引导文本 + 链接文本（`5:3`）+ 外链图标（`5:4`）。
  - 链接文本设 `hyperlink` + accent 色 #1A4E79 + 下划线，作为行内可点击链接；并为容器/页面高度 +80px 防裁切（`2:18`/`2:15`/`2:2`/`2:16`/`2:17`/`2:19`）。
  - 新增顶层弹窗帧 `5:9`（1280×800，dim 遮罩 #10100E@0.5）+ 居中卡片 `5:10`（白底、圆角 14、三层 DROP_SHADOW）：域名 chip（globe 图标）+ 关闭按钮 + 标题 + 分隔线 + URL + 描述 + 「取消/在新标签页打开」按钮（按钮文本也带 hyperlink）。
  - 给链接文本 `5:3` 加 `reactions:[{trigger:{type:'ON_CLICK'},actions:[{type:'NODE',destinationId:'5:9'}]}]` 实现点击打开弹窗。
- **关键坑（已确认格式）**：
  - `hyperlink` 必须是 `{type:"URL", value:"https://..."}`（用 `value` 不用 `url`，否则报错 "Expected string at .value"）。
  - `document` 预定义绑定在本部署不可用 → 顶层帧父节点用页面真实 id `0:1`（不是 'document'）。
  - `counterAxisAlignItems` 仅支持 MIN/MAX/CENTER/BASELINE，**不支持 STRETCH**；要让子节点横向撑满请用子节点 `width:"fill_container"`。
  - `reactions` 按上述格式可被接受（无报错），视为有效的点击原型。
