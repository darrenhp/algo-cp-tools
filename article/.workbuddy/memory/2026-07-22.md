## 修正：用户不要弹窗，改为纯新标签页外链

用户反馈「不需要有这个弹窗」，站外链接应点击直接新标签页打开（如
`https://atcoder.jp/contests/dp/submissions/45905298`，源文形式幂级数.md:492 已有此 URL）。

**改法**：
- 删掉三处生成器里所有 `#lp-modal` 弹窗 CSS 与弹窗 JS（modal DOM 构建 + openModal/closeModal +
  点击/keydown 事件），链接改为直接 `<a target="_blank" rel="noopener noreferrer">`。
- CSS 仅保留 `.lp-link{... underline}` + `.lp-link::after{content:"↗";...}`（外链小箭头）。
- 用 `_patch_strip_popup.py` 做替换（匹配整段 modal 块），跑完即删。

**踩坑（重要）**：最初把弹窗块结尾的 `})();`（闭合第二个 IIFE）误替换成 `)();`，
少了一个 `}`，导致整段 JS 语法错误（`node --check` 报 unexpected token `)`）。
修复：把 `  }\n)();` 改回 `  }\n})();`（用 `_fix_iife.py`，跑完即删）。
教训：删除大段代码时，结尾的 `})();` 里那个 `}` 往往是在闭合外层 IIFE，不能一并删。

**验证**：三篇重新生成；`node --check` 三个抽取 JS 均 OK；`grep` 确认无 `lp-modal`/`openModal` 残留；
静态 HTML 里 URL 仍是纯文本（链接由运行时 JS 注入，正常）；源文 atcoder 45905298 会被自动转成新标签页外链。
