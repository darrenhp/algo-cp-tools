说明

            
    
              
  • 支持区间 [L, R]，L ≥ 1，R ≤ 10,000,000

    • 
              
  • 使用线性筛 O(R) 一次性计算所有数论函数
    • 
              
  • 勾选/取消列可即时切换表格列显隐
    • 
              
  • 方向切换：横向（每行一个数）/ 竖向（每列一个数，转置）
    • 
              
  • 素数个数与最大因数个数为全量统计，与显示行数无关

函数含义

            
    
              
  • 素数：n 是否为素数
    • 
              
  • μ(n) 莫比乌斯函数：素数=−1，含平方因子=0，否则=(−1)^k（k 为不同质因子数）
    • 
              
  • φ(n) 欧拉函数：≤ n 且与 n 互素的正整数个数
    • 
              
  • d(n) 约数个数：n 的正约数总数
    • 
              
  • σ(n) 约数和：n 的所有正约数之和
    • 
              
  • ω/Ω：ω=不同质因子个数，Ω=总质因子个数（含重复）
    • 
              
  • 质因数分解：如 12 → 2²×3（上标用 Unicode）
    • 
              
  • 约数列表：升序排列的全部正约数
    •

右侧实时显示函数图像（多函数叠加、自动缩放，忽略极端离群值以避免渐近线撑爆画面）。多函数每行一个（因 comb(n,k) 等内建函数含逗号，分隔符改用换行而非逗号）。

支持全部内建函数（含 gcd/lcm/comb/factorial/eulerPhi/primeCount/divisorCount/omega/bigomega/mobius/partitionNumber/isPrime/nextPrime/factorize 等）。其中数论类函数仅对正整数自变量有效：跨实数区间时会自动隐藏非整数点，仅显示整数点；若 x 范围不含整数则给出提示。

                
提示：勘察数论函数可用整数型范围，例如 x ∈ [1, 30]、采样点 30，绘制 eulerPhi(x)、primeCount(x)、mobius(x) 等。

规模估算对指数 / 阶乘类（2ⁿ、n!、comb、perm）采用对数尺度，避免大数溢出。

              

              

                
                

                  
                  
                  
                  
                  
                  
                  
                  
                

              

              

                
                
                

                  
                  
                  
                  
                  
                

                
              

              

              

                
仅评估最大数据范围内的计算量规模（不计算精确值），以科学计数法（如 1e10）输出，并提示竞赛时限内的可行性。

                
对指数 / 阶乘类（2ⁿ、n!）采用对数尺度估算数量级，避免大数溢出。

                
表达式中自变量为 n，支持全部通用计算函数（见「表达式与符号运算」清单），例如：n^2、n*log(n)、n*log2(n)、2^n、n!、comb(n,2)、perm(n,3)、factorial(n)、gcd(n,7) 等均可参与规模估算。

符号代数求解（基于 nerdamer，缺载时回退 Algebrite）：对含参数的方程做移项整理，输出指定变量的解析表达式。
